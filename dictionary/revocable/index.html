すし辞書 / revocable

revocable

音声は端末の読み上げ機能を使用します。

形容詞

  1. 撤回可能な、取り消せる

    able to be officially canceled, withdrawn, or taken back

    The agreement grants a revocable license to use the images.

    その契約は画像の使用について取り消し可能な許諾を与えている。

    Access to the database is revocable if the rules are violated.

    規則に違反した場合、データベースへのアクセス権は取り消されることがある。

よく使う組み合わせ

  • a revocable license：取り消し可能な許諾
  • revocable consent：撤回可能な同意
  • a revocable agreement：解除・撤回可能な合意

revoke（撤回する）の形容詞。対義語は irrevocable（取り消せない）。
