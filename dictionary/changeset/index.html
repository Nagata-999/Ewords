changeset

音声は端末の読み上げ機能を使用します。

名詞

  1. 変更内容のまとまり；変更セット

    a group of related modifications treated as one unit in version control or software development

    The developer reviewed the changeset before merging it into the main branch.

    開発者はメインブランチに統合する前に変更セットを確認した。

    Each changeset includes a short description of the files it modifies.

    各変更セットには変更対象ファイルの簡単な説明が含まれる。

よく使う組み合わせ

  • review a changeset：変更セットをレビューする
  • apply a changeset：変更セットを適用する
  • changeset history：変更セットの履歴

ソフトウェア開発で複数の関連する変更をひとまとまりとして扱う語。
