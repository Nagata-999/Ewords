notation

音声は端末の読み上げ機能を使用します。

名詞

  1. 記号法；表記法

    a system of signs or symbols used to represent information

    The textbook introduces a simpler notation for the formula.

    その教科書はその式のために、より簡単な表記法を導入している。

  2. 楽譜の記譜法

    a system of written symbols used to represent musical sounds

    Students learn basic musical notation before reading full scores.

    生徒たちは総譜を読む前に基本的な記譜法を学ぶ。

よく使う組み合わせ

  • mathematical notation：数学的表記法
  • musical notation：楽譜の記譜法

数学・科学では記号体系、音楽では音符や休符などの表記体系を指す。
