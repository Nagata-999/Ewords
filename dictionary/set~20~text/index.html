すし辞書 / set text

set text

音声は端末の読み上げ機能を使用します。

名詞

  1. 指定図書；授業・試験の課題作品

    a book or other work officially chosen for students to study in a course or examination

    The class discussed the set text before writing their essays.

    生徒たちは小論文を書く前に指定作品について話し合った。

    Students must read two set texts for the literature examination.

    生徒たちは文学の試験に向けて指定作品を二冊読まなければならない。

よく使う組み合わせ

  • a literature set text：文学の指定作品
  • study a set text：指定作品を学習する
  • set texts for an exam：試験の指定図書

主にイギリス英語。教科書一般ではなく、授業や試験で指定された作品を指す。
