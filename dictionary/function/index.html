function

音声は端末の読み上げ機能を使用します。

名詞

  1. 機能；役割

    the purpose or job of a thing, system, or organ

    One function of the immune system is to recognize pathogens.

    免疫系の機能の一つは病原体を認識することだ。

    The main function of the heart is to pump blood.

    心臓の主な機能は血液を送り出すことです。

  2. 関数

    a mathematical relationship in which an input determines an output

    The position is expressed as a function of time.

    位置は時間の関数として表される。

動詞

  1. 機能する；作動する

    to work or operate in the intended way

    The device can function without an internet connection.

    その装置はインターネット接続なしでも作動する。

    The system cannot function without electricity.

    そのシステムは電気なしでは機能しません。
