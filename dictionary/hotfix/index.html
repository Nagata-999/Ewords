hotfix

音声は端末の読み上げ機能を使用します。

名詞

  1. 緊急修正；緊急修正プログラム

    a small, urgent software change released to fix a specific problem

    The developers issued a hotfix for a bug that prevented students from signing in.

    開発者たちは、生徒がログインできない不具合に対して緊急修正を公開した。

    We tested the hotfix before applying it to the live website.

    本番サイトに適用する前に、その緊急修正をテストした。

よく使う組み合わせ

  • release a hotfix：緊急修正を公開する
  • apply a hotfix：緊急修正を適用する
  • security hotfix：セキュリティ上の緊急修正

通常の機能追加より緊急性が高い修正。急ぐ場合も本番適用前の確認が重要。
