すし辞書 / server

server

音声は端末の読み上げ機能を使用します。

名詞

  1. （ネットワークの）サーバー

    a computer or program that provides data or services to other computers

    The university stores research data on a secure server.

    その大学は研究データを安全なサーバーに保存している。

    The website was unavailable because the server had failed.

    サーバーに障害が発生したため、そのウェブサイトを利用できなかった。

  2. （レストランの）給仕係；接客係

    a person who serves food and drinks in a restaurant, especially in American English

    Our server explained which dishes contained nuts.

    接客係はどの料理にナッツが含まれているか説明してくれた。

よく使う組み合わせ

  • web server：ウェブサーバー
  • secure server：安全性が確保されたサーバー
  • server outage：サーバー障害
  • restaurant server：レストランの接客係

ITでは「サーバー」、米国英語の飲食店では「接客係」。serve（動詞）と区別する。
