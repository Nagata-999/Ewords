すし辞書 / build

build

音声は端末の読み上げ機能を使用します。

動詞

  1. 建てる；建設する

    to construct a structure by putting materials together

    The city plans to build a new public library.

    市は新しい公共図書館を建設する計画だ。

  2. （関係・信頼などを）築く

    to develop something gradually through effort

    Consistent communication helps build trust among team members.

    一貫した意思疎通はチームの信頼関係を築く助けになる。

    It takes time to build trust between people.

    人と人との信頼を築くには時間がかかります。

  3. （証拠・議論などを）積み重ねて形成する

    to develop an argument or body of evidence step by step

    The researchers built a strong case for changing the policy.

    研究者たちは政策変更を支持する有力な根拠を積み重ねた。

語形変化

よく使う組み合わせ

  • build a house：家を建てる
  • build trust：信頼を築く
  • build a case for reform：改革の根拠を積み上げる
  • build on previous research：先行研究を土台に発展させる

build–built–built。build trust/relationships は抽象的な「築く」。build on ～ は「～を基礎として発展させる」。
