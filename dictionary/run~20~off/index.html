すし辞書 / run off

run off

音声は端末の読み上げ機能を使用します。

動詞

  1. （急いで）逃げ去る

    to leave a place quickly, often to escape or avoid something

    The suspect ran off before the police arrived.

    警察が到着する前に容疑者は逃げ去った。

  2. （文書を）急いで印刷する

    to produce printed copies of a document

    Could you run off thirty copies of the handout before the meeting?

    会議前に配布資料を30部印刷してもらえますか。

  3. （雨水などが地表を）流れ去る

    to flow away from a surface

    During heavy rain, water runs off paved surfaces into nearby drains.

    大雨の際、水は舗装面から流れ出て近くの排水溝に入る。

よく使う組み合わせ

  • run off quickly：急いで逃げ去る
  • run off copies：文書を印刷する
  • rainwater runs off：雨水が流れ去る

run off は逃走・印刷・表面流出の異なる語義を持つ。雨水の文脈では run off into ... が自然。
