すし辞書 / should

should

音声は端末の読み上げ機能を使用します。

助動詞

  1. 〜すべきだ；〜したほうがよい

    used to give advice or say what is appropriate

    Students should verify information before citing it.

    生徒は情報を引用する前にその正確さを確かめるべきだ。

  2. 〜のはずだ

    used to express what is expected or likely

    The parcel should arrive by Thursday.

    荷物は木曜日までに届くはずだ。

よく使う組み合わせ

  • should consider：検討したほうがよい
  • should be able to：〜できるはずだ
  • should have checked：確認しておくべきだった

should + 動詞の原形。should have + 過去分詞は「〜すべきだったのに」の後悔・批判を表せる。
