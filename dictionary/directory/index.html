directory

音声は端末の読み上げ機能を使用します。

名詞

  1. 名簿；住所録；案内一覧

    a list of people, organizations, or places with information about them

    The school directory includes emergency contact numbers.

    学校の名簿には緊急連絡先が載っている。

    Check the online directory for the department’s address.

    学部の住所はオンライン名簿で確認してください。

  2. （コンピューターの）ディレクトリ；フォルダー

    a location in a computer file system that contains files or other directories

    Save the images in a separate directory.

    画像は別のディレクトリに保存してください。

よく使う組み合わせ

  • staff directory：職員名簿
  • online directory：オンライン名簿
  • root directory：ルートディレクトリ

人名・施設の一覧と、コンピューターのフォルダーという二つの意味を区別する。
