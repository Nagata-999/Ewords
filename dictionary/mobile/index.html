mobile

音声は端末の読み上げ機能を使用します。

形容詞

  1. 移動可能な；移動式の

    able to move or be moved easily from one place to another

    The clinic uses a mobile unit to reach remote villages.

    その診療所は遠隔地の村に出向くため移動式の設備を使っている。

    その診療所は遠隔地の村へ行くため移動式設備を使っています。

  2. 携帯型の；モバイルの

    designed to be used while moving or away from a fixed location

    Mobile devices have changed how students access information.

    携帯端末は生徒の情報へのアクセス方法を変えた。

よく使う組み合わせ

  • a mobile phone：携帯電話
  • a mobile device：携帯端末
  • a mobile clinic：移動診療所

mobile phone は主に英国英語、米国英語では cell phone も一般的。mobile は移動可能なもの全般にも使う。
