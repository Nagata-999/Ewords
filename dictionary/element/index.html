element

音声は端末の読み上げ機能を使用します。

名詞

  1. 要素；構成部分

    one part of a larger whole, especially an important or necessary part

    Trust is a key element of effective teamwork.

    信頼は効果的なチームワークの重要な要素である。

    Public participation is an essential element of the planning process.

    市民の参加は計画策定過程に不可欠な要素である。

  2. （化学）元素

    a pure substance made up of atoms with the same number of protons

    Carbon is an element found in all known living organisms.

    炭素は既知のすべての生物に含まれる元素である。

よく使う組み合わせ

  • key element：重要な要素
  • essential element：不可欠な要素
  • chemical element：化学元素
  • element of uncertainty：不確実な要素

element of A は「Aという要素」。化学では element は「元素」で、compound（化合物）と区別する。
