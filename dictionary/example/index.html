example

音声は端末の読み上げ機能を使用します。

名詞

  1. 例；実例

    a particular case used to explain a general idea

    The teacher used a real-world example to explain opportunity cost.

    教師は機会費用を説明するために実社会の例を用いた。

    Can you give me an example of how this expression is used?

    この表現がどのように使われるか例を挙げてもらえますか。

  2. 手本；模範

    a person or action that others can learn from or imitate

    Her commitment to fairness sets an example for the whole team.

    公平さを大切にする彼女の姿勢はチーム全体の手本となる。

よく使う組み合わせ

  • for example：例えば
  • set an example：手本を示す
  • a typical example：典型的な例

for example は例示、set an example は手本を示す。such as は後ろに名詞句を置く。
