すし辞書 / probably

probably

音声は端末の読み上げ機能を使用します。

副詞

  1. おそらく

    used when something is likely to be true or happen

    It will probably rain this evening.

    今晩はおそらく雨が降るでしょう。

    The results will probably change when we collect more data.

    さらにデータを集めれば、結果はおそらく変わるだろう。

よく使う組み合わせ

  • will probably happen：おそらく起こるだろう
  • probably because：おそらく〜が理由で
  • most probably：おそらく；十中八九

probably は確率が高いと考えるときの副詞。助動詞の後・一般動詞の前に置くことが多い（will probably / probably need）。

語源

Latin probare

probable + -ly。probable は probare「試す・証明する」に由来し、もっともらしいことを表す。

  • prob / prov：試す・証明する

関連語：probability · prove · proof · approve
