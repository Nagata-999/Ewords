garbage collection

音声は端末の読み上げ機能を使用します。

名詞

  1. 不要になったメモリーの自動回収

    automatic recovery of computer memory that a program no longer needs

    Garbage collection can briefly pause an application when memory is reclaimed.

    不要メモリーの回収時にアプリが一時的に停止することがある。

    The runtime handles garbage collection so developers do not free every object manually.

    実行環境が不要メモリーの回収を行うため、開発者はすべてのオブジェクトを手動で解放する必要がない。

  2. ごみの収集

    the organized removal of household or commercial waste

    Garbage collection takes place twice a week in this neighborhood.

    この地域では週に二回ごみが収集される。

よく使う組み合わせ

  • automatic garbage collection：自動ガベージコレクション
  • garbage collection pause：メモリー回収による一時停止
  • municipal garbage collection：自治体によるごみ収集

コンピューター分野と日常生活では意味が異なる。略語は GC。
