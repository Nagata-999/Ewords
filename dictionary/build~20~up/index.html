build up

音声は端末の読み上げ機能を使用します。

動詞

  1. 徐々に増やす；積み重ねる

    to increase or develop something gradually over time

    The school built up a library of student-made learning materials.

    その学校は生徒が作った教材を少しずつ蓄積した。

    Regular practice helps students build up confidence.

    継続的な練習は生徒が自信を積み上げるのに役立つ。

  2. （力・自信などを）養う；高める

    to develop strength, confidence, or ability through repeated effort

    Short presentations help learners build up confidence.

    短い発表を重ねると学習者は自信をつけられる。

よく使う組み合わせ

  • build up confidence：自信をつける
  • build up savings：貯蓄を増やす
  • build up over time：時間とともに蓄積する

build up は他動詞・自動詞の両方で使う。build it up のように代名詞は間に置く。
