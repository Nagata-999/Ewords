すし辞書 / same

same

音声は端末の読み上げ機能を使用します。

形容詞

  1. 同じ；同一の

    identical or not different in the relevant way

    The two groups received the same instructions.

    2つのグループは同じ指示を受けた。

    We reached the same conclusion using different methods.

    異なる方法を使って同じ結論に達しました。

代名詞

  1. 同じもの；同じこと

    the identical thing or situation already mentioned

    The first method worked, and the same was true of the second.

    最初の方法はうまくいき、2番目も同様だった。

よく使う組み合わせ

  • at the same time：同時に
  • the same as before：以前と同じ
  • the same applies to：〜にも同じことが当てはまる

the same asが基本形（the same withとは異なる）。sameの前には通常theを付ける。the same is true of ...は論述で便利な表現。
