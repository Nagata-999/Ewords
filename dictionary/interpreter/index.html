interpreter

音声は端末の読み上げ機能を使用します。

名詞

  1. 通訳者

    a person who translates spoken or signed communication between languages

    An interpreter helped the patient explain her symptoms.

    通訳者は患者が症状を説明するのを手伝った。

    The conference provided interpreters for international guests.

    その会議は海外からの参加者に通訳者を用意した。

  2. インタープリター；逐次実行処理系

    a program that executes instructions written in another programming language

    The interpreter reports a syntax error on line twelve.

    インタープリターは12行目の構文エラーを報告した。

    A Python interpreter executes the script.

    Pythonのインタープリターがスクリプトを実行する。

よく使う組み合わせ

  • conference interpreter：会議通訳者
  • sign-language interpreter：手話通訳者
  • Python interpreter：Pythonインタープリター

人の interpreter は通訳者。コンピューター分野ではプログラムを実行する処理系を指す。
