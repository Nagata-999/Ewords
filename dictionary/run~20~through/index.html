run through

音声は端末の読み上げ機能を使用します。

動詞

  1. （手順・説明などを）ざっと確認する

    to review or explain something from beginning to end

    Let’s run through the safety instructions before we begin.

    始める前に安全上の注意事項を一通り確認しよう。

  2. （発表などを）通して練習する

    to rehearse a performance or presentation from start to finish

    We ran through the presentation twice before the conference.

    私たちは会議前にプレゼンを二度通して練習した。

よく使う組み合わせ

  • run through the procedure：手順を一通り確認する
  • run through a presentation：発表を通して練習する

run through + 目的語。「通しで行う」「順に確認する」。run out of（使い果たす）と区別。
