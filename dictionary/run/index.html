すし辞書 / run

run

音声は端末の読み上げ機能を使用します。

動詞

  1. 走る

    to move quickly on foot

    I run five kilometers every morning.

    私は毎朝5キロ走ります。

  2. 運営する

    to manage a business or organization

    She runs a small company.

    彼女は小さな会社を経営しています。

  3. 作動する

    to operate or function

    The machine is running normally.

    その機械は正常に作動しています。

  4. 液体が流れる；流す

    to flow or cause a liquid to flow

    Cold water ran from the tap.

    蛇口から冷たい水が流れました。

  5. 道などが延びる；路線が通る

    to extend along a particular path or between places

    A narrow path runs beside the river.

    川に沿って細い小道が延びています。

  6. 選挙に立候補する

    to compete for an elected position

    She decided to run for mayor.

    彼女は市長選に立候補することを決めました。

名詞

  1. 走ること；ひと走り

    a period or outing spent running, often for exercise

    We went for a short run before breakfast.

    朝食前に少し走りに出かけました。

使い方・語法

走る・経営する・機械が作動するほか、液体が流れる、道が延びるなどに使う。run for + 役職は立候補すること。
