linter

音声は端末の読み上げ機能を使用します。

名詞

  1. 静的解析によってコードの問題を指摘するツール

    a tool that checks source code for likely errors, style violations, or suspicious patterns without running it

    The linter flagged an unused variable in the JavaScript file.

    リンターはJavaScriptファイル内の未使用変数を指摘した。

    Running a linter before committing code can prevent simple mistakes.

    コードをコミットする前にリンターを実行すると、単純なミスを防ぎやすい。

よく使う組み合わせ

  • run a linter：リンターを実行する
  • linter warning：リンターの警告
  • linter configuration：リンターの設定

linter は主に静的検査を行う。実行時の挙動まで保証するテストツールではない。
