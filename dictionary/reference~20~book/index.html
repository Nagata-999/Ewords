すし辞書 / reference book

reference book

音声は端末の読み上げ機能を使用します。

名詞

  1. 参考図書；調べ物に使う本

    a book consulted for particular facts or explanations rather than usually read from beginning to end

    The library keeps dictionaries and other reference books near the entrance.

    図書館は辞書などの参考図書を入口付近に置いている。

    Use a reliable reference book to check the dates of the events.

    出来事の日付を確かめるには信頼できる参考図書を使いなさい。

よく使う組み合わせ

  • consult a reference book：参考図書で調べる
  • reliable reference book：信頼できる参考図書
  • reference book section：参考図書コーナー

reference book は辞書・百科事典などの調査用の本を含む。日本語の「受験参考書」は study guide / exam preparation book の方が自然な場合がある。
