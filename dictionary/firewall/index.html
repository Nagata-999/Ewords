firewall

音声は端末の読み上げ機能を使用します。

名詞

  1. （コンピューターの）ファイアウォール

    a system that prevents unauthorized access to or from a computer network

    The firewall blocked an unauthorized connection.

    ファイアウォールは許可されていない接続を遮断した。

    A properly configured firewall can block many unauthorized connections.

    適切に設定されたファイアウォールは多くの不正接続を遮断できる。

    The administrator updated the firewall rules after reviewing the security logs.

    管理者はセキュリティログを確認した後、ファイアウォールの規則を更新した。

  2. 防火壁

    a wall designed to prevent a fire from spreading between parts of a building

    A firewall separates the storage area from the offices.

    防火壁が倉庫部分と事務室を隔てている。

よく使う組み合わせ

  • configure a firewall：ファイアウォールを設定する
  • firewall rules：ファイアウォールの通信規則
  • network firewall：ネットワーク用ファイアウォール
  • firewall protection：ファイアウォールによる保護

ネットワーク用語。建築では延焼を防ぐ「防火壁」も指す。
