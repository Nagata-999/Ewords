set off

音声は端末の読み上げ機能を使用します。

動詞

  1. 出発する

    to begin a journey

    We set off early to avoid heavy traffic.

    渋滞を避けるため早朝に出発した。

    We set off before the roads became busy.

    道路が混む前に出発した。

  2. 引き起こす

    to cause an event or reaction to begin

    The announcement set off a wave of protests.

    その発表は抗議の波を引き起こした。

  3. 作動させる

    to cause an alarm or explosive device to operate

    Smoke from the kitchen set off the fire alarm.

    台所の煙で火災報知器が作動した。

よく使う組み合わせ

  • set off at dawn：夜明けに出発する
  • set off a reaction：反応を引き起こす
  • set off an alarm：警報を作動させる

自動詞の set off は「出発する」、他動詞の set off は「引き起こす・作動させる」。
