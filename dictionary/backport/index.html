backport

音声は端末の読み上げ機能を使用します。

動詞

  1. 新しい版の修正を古い版へ移植する

    to adapt a software fix or feature from a newer version for use in an older version

    The team will backport the security fix to the previous release.

    チームはセキュリティ修正を旧版にも移植する予定だ。

    Developers backported the patch so older devices could remain protected.

    開発者たちは古い端末も保護されるようパッチを旧版へ移植した。

よく使う組み合わせ

  • backport a patch：パッチを旧版へ移植する
  • backport a security fix：セキュリティ修正を旧版へ移植する
  • backport to an older version：古い版へ移植する

ソフトウェア開発用語。backport A to B の形で使う。
