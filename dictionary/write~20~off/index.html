write off

音声は端末の読み上げ機能を使用します。

動詞

  1. （人・計画などを）見込みなしと決めつける

    to dismiss someone or something as unlikely to succeed or be useful

    Many observers wrote off the proposal, but the pilot program produced promising results.

    多くの識者はその提案を見込みなしと見なしたが、試験事業は有望な結果を出した。

    It is too early to write off the new approach.

    その新しい手法を見限るにはまだ早すぎる。

  2. （債権・資産などを）損失として処理する

    to remove the value of a debt or asset from financial accounts because it cannot be recovered

    The bank wrote off part of the loan after the company went bankrupt.

    その会社が破産した後、銀行は融資の一部を貸倒損失として処理した。

よく使う組み合わせ

  • write off an idea：考えを見込みなしと判断する
  • write off a debt：債権を貸倒処理する
  • write someone off：人を見限る

write off A / write A off。金融用法では「帳簿上の損失として処理する」。
