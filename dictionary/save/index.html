save

音声は端末の読み上げ機能を使用します。

動詞

  1. 救う

    to prevent someone or something from being harmed or destroyed

    The lifeguard saved a child from drowning.

    監視員は子どもが溺れるのを救った。

  2. 節約する

    to avoid using more time, money, or resources than necessary

    Taking the train saves us an hour.

    電車を使えば1時間節約できる。

  3. 保存する

    to store digital information so that it can be used later

    Save a copy of your essay before editing it.

    作文を編集する前にコピーを保存しなさい。

    Save the document before closing the program.

    プログラムを閉じる前に文書を保存してください。

  4. 蓄える

    to keep money for future use

    She is saving for a trip abroad.

    彼女は海外旅行のために貯金している。

よく使う組み合わせ

  • save a life：命を救う

save A from B は「AをBから救う」。save up for は「〜のために貯金する」。
