vector

音声は端末の読み上げ機能を使用します。

名詞

  1. ベクトル；大きさと方向を持つ量

    a quantity that has both magnitude and direction

    Velocity is a vector because it specifies both speed and direction.

    速度は速さと方向の両方を示すためベクトル量である。

  2. 病原体の媒介生物

    an organism that carries and transmits a disease-causing agent

    Mosquitoes can act as vectors for several infectious diseases.

    蚊は複数の感染症の媒介生物になり得る。

  3. ベクター画像の図形情報

    a graphic element represented by mathematical paths rather than pixels

    The logo was saved as a vector so it could be enlarged without losing sharpness.

    そのロゴは拡大しても鮮明さを失わないよう、ベクター形式で保存された。

よく使う組み合わせ

  • disease vector：病気の媒介生物
  • vector quantity：ベクトル量
  • vector graphics：ベクター画像

数学・疫学・画像処理で意味が異なる。単なる「方向」だけでは数学の vector の説明として不十分。
