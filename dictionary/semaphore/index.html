semaphore

音声は端末の読み上げ機能を使用します。

名詞

  1. 並行処理で共有資源へのアクセスを制御する仕組み

    a synchronization mechanism that uses a counter to control access to shared resources

    The semaphore limits the number of tasks that can use the database at once.

    セマフォは同時にデータベースを使える処理の数を制限する。

    A task must release the semaphore after finishing its work.

    処理が終わったら、そのタスクはセマフォを解放しなければならない。

  2. 旗や腕の位置で情報を伝える信号方式

    a system of communicating messages by using the positions of flags or arms

    The sailors practiced semaphore signals on the deck.

    船員たちは甲板で手旗信号を練習した。

    Before radio became widespread, semaphore could convey messages visually.

    無線が普及する前は、手旗信号などで視覚的に情報を伝えられた。

よく使う組み合わせ

  • binary semaphore：二値セマフォ
  • counting semaphore：計数セマフォ
  • semaphore signal：手旗信号

In computing, a semaphore coordinates concurrent tasks; outside computing, it can mean visual signaling.
