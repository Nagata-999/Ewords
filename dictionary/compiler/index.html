compiler

音声は端末の読み上げ機能を使用します。

名詞

  1. コンパイラー；ソースコードを翻訳するプログラム

    a program that translates source code into another form, often executable machine code

    The compiler found a type error before the program ran.

    コンパイラーはプログラムの実行前に型エラーを発見した。

    Different compilers may produce different machine code.

    異なるコンパイラーは異なる機械語コードを生成することがある。

  2. 編纂者；編集してまとめる人

    a person who collects and organizes information into a book or list

    The compiler of the dictionary checked the historical sources.

    その辞書の編纂者は歴史資料を確認した。

    The compiler arranged the entries by topic.

    編纂者は項目を話題別に整理した。

よく使う組み合わせ

  • compiler error：コンパイラーのエラー
  • compiler optimization：コンパイラーによる最適化
  • dictionary compiler：辞書編纂者

プログラミングでは compiler はコードを翻訳する処理系。書籍などでは資料の編纂者。
