cherry-pick

音声は端末の読み上げ機能を使用します。

動詞

  1. 都合のよいデータ・事例だけを選ぶ

    to select only evidence that supports a preferred view while ignoring other relevant evidence

    The article cherry-picked statistics and ignored the wider trend.

    その記事は都合のよい統計だけを選び、全体的な傾向を無視した。

    It is misleading to cherry-pick data that support only one side of the argument.

    議論の一方だけを支持するデータを選り好みするのは誤解を招く。

  2. （ソフト開発で）特定の変更だけを別の枝へ取り込む

    to apply selected changes from one branch of a software project to another

    The developer cherry-picked the security fix into the release branch.

    開発者はセキュリティ修正だけをリリース用ブランチに取り込んだ。

よく使う組み合わせ

  • cherry-pick evidence：都合のよい証拠だけを選ぶ
  • cherry-pick data：データを選り好みする
  • cherry-pick a commit：特定のコミットだけを取り込む

議論での cherry-pick は偏った選択を非難する語。Git などでは特定のコミットを取り込む技術用語。
