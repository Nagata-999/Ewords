memory

音声は端末の読み上げ機能を使用します。

名詞

  1. 記憶力；覚える能力

    the ability to store and remember information

    Regular sleep supports memory and concentration.

    規則正しい睡眠は記憶力と集中力を支える。

    Sleep plays an important role in memory.

    睡眠は記憶に重要な役割を果たします。

    Retrieval practice can strengthen long-term memory.

    想起練習は長期記憶を強化することがある。

  2. 思い出；記憶している出来事

    something that a person remembers from the past

    My clearest memory of the trip is the sunrise over the mountains.

    その旅行で最も鮮明に覚えているのは山々に昇る朝日だ。

  3. 記憶装置；メモリ

    the part of a computer that stores data or instructions

    The program needs more memory to process large images.

    そのプログラムが大きな画像を処理するには、より多くのメモリが必要だ。

よく使う組み合わせ

  • short-term memory：短期記憶
  • childhood memory：子どもの頃の思い出
  • memory capacity：記憶容量

memory は能力の意味では不可算、個々の思い出では可算（a memory）。コンピューターのメモリにも使う。

語源

Latin memor / memoria

Latin memoria / memor「心に留めている」に由来する。

  • mem / memor：覚える・記憶

関連語：memorial · remember
