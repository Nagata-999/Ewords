object

音声は端末の読み上げ機能を使用します。

名詞

  1. 物体；物

    a physical thing that can be seen or touched

    The sensor detects objects within two meters.

    そのセンサーは2メートル以内の物体を検知する。

    The telescope can track a moving object in the sky.

    その望遠鏡は空の動く物体を追跡できます。

  2. 目的；目標

    the purpose or intended result of an action

    The object of the exercise is to compare two explanations.

    その演習の目的は二つの説明を比較することだ。

動詞

  1. （～に）反対する；異議を唱える

    to express disagreement with a plan, action, or statement

    Several residents objected to the proposed road expansion.

    数人の住民が道路拡張案に反対した。

よく使う組み合わせ

  • an everyday object：日用品
  • object to a proposal：提案に反対する

動詞 object to ... の to は前置詞。目的語には名詞・動名詞を置く。
