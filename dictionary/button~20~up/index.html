すし辞書 / button up

button up

音声は端末の読み上げ機能を使用します。

動詞

  1. （服の）ボタンを留める

    to fasten the buttons of a shirt, coat, or other garment

    Button up your coat before going outside.

    外に出る前にコートのボタンを留めなさい。

    The child learned to button up his own shirt.

    その子は自分でシャツのボタンを留められるようになった。

  2. （仕事・計画などを）きちんと仕上げる

    to finish the remaining details of a task or arrangement

    We need to button up the budget before the meeting.

    会議前に予算の細部をきちんと仕上げる必要がある。

よく使う組み合わせ

  • button up a shirt：シャツのボタンを留める
  • button up a coat：コートのボタンを留める
  • button up the details：細部を詰める

服では button up something / button something up。仕事を「仕上げる」は主に米語の口語表現。
