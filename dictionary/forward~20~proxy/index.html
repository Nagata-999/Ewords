forward proxy

音声は端末の読み上げ機能を使用します。

名詞

  1. フォワードプロキシ；利用者側の代理中継装置

    a server that sends requests to external services on behalf of client devices

    The school uses a forward proxy to manage access to external websites.

    学校は外部ウェブサイトへのアクセスを管理するため、フォワードプロキシを利用している。

    A forward proxy may cache frequently requested pages to reduce network traffic.

    フォワードプロキシは頻繁に要求されるページをキャッシュし、通信量を減らすことがある。

よく使う組み合わせ

  • forward proxy server：フォワードプロキシサーバー
  • forward proxy configuration：フォワードプロキシの設定
  • use a forward proxy：フォワードプロキシを使う

クライアントの代理として外部へ要求を送る仕組み。reverse proxy とは配置と役割が異なる。
