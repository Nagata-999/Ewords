try

音声は端末の読み上げ機能を使用します。

動詞

  1. ～しようと試みる

    to make an effort to do something, whether or not it succeeds

    Try using a different example if the explanation is unclear.

    説明が分かりにくければ別の例を使ってみてください。

  2. 試しにやってみる；試用する

    to test a method, product, or activity to see whether it works or is enjoyable

    Try restarting the app before changing the settings.

    設定を変える前にアプリを再起動してみてください。

名詞

  1. 試み；挑戦

    an attempt to do something, especially when success is uncertain

    The first design failed, but the second try worked.

    最初の設計は失敗したが、2回目の試みはうまくいった。

よく使う組み合わせ

  • try to do something：～しようと努力する
  • try doing something：試しに～してみる
  • give it a try：試してみる

try to do は「～しようと努力する」、try doing は「試しに～してみる」。意味の違いに注意。
