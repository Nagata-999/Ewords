instrument

音声は端末の読み上げ機能を使用します。

名詞

  1. 器具；測定機器

    a tool or device used for a particular purpose

    The instrument measures changes in air pressure.

    その機器は気圧の変化を測定する。

  2. 楽器

    an object used to produce musical sounds

    Learning a musical instrument takes regular practice.

    楽器を習得するには定期的な練習が必要だ。

  3. 手段；政策手段

    something used to achieve a particular result

    Tax policy can be an instrument of social change.

    税制は社会変革の手段になり得る。
