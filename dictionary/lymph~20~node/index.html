すし辞書 / lymph node

lymph node

音声は端末の読み上げ機能を使用します。

名詞

  1. リンパ節

    a small structure in the lymphatic system that filters lymph and helps the body respond to infection

    The doctor checked the lymph nodes in her neck.

    医師は彼女の首のリンパ節を調べた。

    Lymph nodes can become swollen during an infection.

    感染症にかかるとリンパ節が腫れることがある。

よく使う組み合わせ

  • swollen lymph nodes：腫れたリンパ節
  • cervical lymph nodes：頸部リンパ節
  • lymph node biopsy：リンパ節生検

lymph はリンパ液、lymph node はリンパ節。lymph gland と呼ぶこともあるが node が標準的。
