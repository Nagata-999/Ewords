すし辞書 / put back

put back

音声は端末の読み上げ機能を使用します。

動詞

  1. （物を）元の場所に戻す

    to return something to the place where it was before

    Put the reference books back on the shelf.

    参考書を棚の元の場所に戻してください。

    Put back the book when you finish.

    読み終わったら本を元の場所に戻してください。

  2. （予定を）延期する

    to move an event to a later time or date

    The organizers put back the meeting by a week.

    主催者は会議を一週間延期した。

語形変化

過去形
put back
過去分詞
put back
三人称単数
puts back
現在分詞
putting back

よく使う組み合わせ

  • put back a book：本を元に戻す
  • put back the deadline：締切を延期する
  • put something back in place：物を元の位置に戻す

put back は分離可能。put it back が自然。会議や締切の延期を表す用法もある。
