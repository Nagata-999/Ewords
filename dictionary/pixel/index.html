pixel

音声は端末の読み上げ機能を使用します。

名詞

  1. 画素；ピクセル

    the smallest individual element of a digital image or display

    The camera sensor captures millions of pixels in each image.

    そのカメラのセンサーは一枚の画像につき数百万の画素を記録する。

よく使う組み合わせ

  • a single pixel：一つの画素
  • pixel density：画素密度
  • dead pixels：点灯しない画素

pixel は picture element の短縮形。画像の解像度を述べるときは pixels を用いる。
