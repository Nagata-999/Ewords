すし辞書 / disk

disk

音声は端末の読み上げ機能を使用します。

名詞

  1. ディスク；データ記録媒体

    a round storage device or medium used to hold computer data

    The technician copied the files to an external disk.

    技術者はファイルを外付けディスクにコピーした。

  2. 円盤状の物

    a thin, flat, circular object

    The machine cuts the metal into small disks.

    その機械は金属を小さな円盤状に切断する。

よく使う組み合わせ

  • hard disk：ハードディスク
  • disk space：ディスクの空き容量
  • optical disk：光ディスク

disk は主にコンピューターの記録媒体に使う綴り。disc は CD などの光ディスクや円盤状の物にも使う。
