set aside

音声は端末の読み上げ機能を使用します。

動詞

  1. （時間・お金を）取っておく

    to reserve time, money, or resources for a particular purpose

    The council set aside funds for school repairs.

    議会は学校の修繕費を確保した。

  2. （意見・感情などを）いったん脇に置く

    to temporarily ignore or put aside a concern or disagreement

    Both sides agreed to set aside their differences.

    双方は意見の違いをいったん脇に置くことで合意した。

  3. （決定・判決を）取り消す

    to officially cancel a legal decision

    The court set aside the earlier ruling.

    裁判所は以前の判決を取り消した。
