failover

音声は端末の読み上げ機能を使用します。

名詞

  1. 障害時の予備システムへの切り替え

    the automatic or planned switching to a backup system when the primary system fails

    The database completed failover within thirty seconds of the outage.

    そのデータベースは障害発生から30秒以内に予備系への切り替えを完了した。

    Regular failover tests help teams find weaknesses before a real incident.

    定期的なフェイルオーバー試験は、実際の障害が起こる前に弱点を見つけるのに役立つ。

よく使う組み合わせ

  • automatic failover：自動フェイルオーバー
  • failover mechanism：障害時の切り替え機構
  • failover testing：フェイルオーバー試験

failover は主系から予備系へ切り替えること。復旧後に元へ戻す操作は failback。
