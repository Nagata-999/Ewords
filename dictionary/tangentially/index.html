すし辞書 / tangentially

tangentially

音声は端末の読み上げ機能を使用します。

副詞

  1. 間接的に；本題から少しそれて

    in a way that is only slightly or indirectly connected to the main subject

    The report addresses climate policy only tangentially.

    その報告書は気候政策に間接的に触れているだけだ。

    Her comment was tangentially related to the original question.

    彼女の発言は元の質問とわずかに関連しているだけだった。

  2. 接線方向に

    along a line that touches a curve or circle at one point

    The object moved tangentially to the circular path when the string broke.

    ひもが切れると物体は円軌道の接線方向に動いた。

よく使う組み合わせ

  • tangentially related to：～と間接的に関連した
  • touch on something tangentially：～に本筋から少しそれて触れる
  • move tangentially：接線方向に動く

比喩では only tangentially related（わずかに関連する）が頻出。
