すし辞書 / fix up

fix up

音声は端末の読み上げ機能を使用します。

動詞

  1. （建物・物などを）修理・改装する

    to repair or improve something that is damaged or in poor condition

    They fixed up the old library so that children could use it again.

    子どもたちが再び使えるように古い図書館を改修した。

  2. （会合・宿泊などを）手配する

    to arrange a meeting, accommodation, or another practical matter

    Can you fix up a meeting with the exchange students?

    交換留学生との面会を手配してもらえますか。

よく使う組み合わせ

  • fix up an old house：古い家を修繕する
  • fix up a meeting：会合を手配する
  • fix someone up with accommodation：人の宿泊先を手配する

fix up + 物 は修理、fix up + 会合などは手配。fix someone up with + 物 は人に物を用意する意味。
