encode

音声は端末の読み上げ機能を使用します。

動詞

  1. 符号化する；特定の形式に変換する

    to represent information using a particular code or system

    The software encodes the audio into a compressed format.

    そのソフトウェアは音声を圧縮形式に符号化する。

    The software encodes the text in a format that different devices can read.

    そのソフトウェアは異なる機器でも読める形式で文字情報を符号化する。

  2. （記憶などに）情報を取り込んで記録する

    to transform information into a form that can be stored in memory

    People often encode information more effectively when they explain it to others.

    人は情報を他人に説明すると、より効果的に記憶へ取り込めることが多い。

    Sleep may help the brain encode newly learned information.

    睡眠は脳が新しく学んだ情報を記憶に取り込むのに役立つ可能性がある。

よく使う組み合わせ

  • encode information as numbers：情報を数値として符号化する
  • encode data in a standard format：標準形式でデータを符号化する
  • encode a memory：記憶として情報を取り込む

Encode is broader than encrypt: encryption specifically protects information from unauthorized reading.
