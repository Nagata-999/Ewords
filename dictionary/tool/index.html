tool

音声は端末の読み上げ機能を使用します。

名詞

  1. 道具；工具

    an object used to perform a practical task

    A sharp knife is an essential tool for a chef.

    よく切れる包丁は料理人に欠かせない道具だ。

    Keep your tools clean and dry after use.

    使った後は工具を清潔で乾いた状態に保ってください。

  2. 手段；役立つもの

    something that helps people achieve a particular aim

    A dictionary is a useful tool for independent study.

    辞書は自主学習に役立つ道具だ。

よく使う組み合わせ

  • a useful tool：役立つ道具
  • digital tools：デジタルツール
  • a tool for learning：学習のための手段

比喩的に「目的を達成するための手段」にも用いる。
