parse

音声は端末の読み上げ機能を使用します。

動詞

  1. （文を）文法的に分析する

    to analyze a sentence into its grammatical parts

    Students learned to parse complex sentences before translating them.

    生徒たちは訳す前に複雑な文の文法構造を分析することを学んだ。

  2. （データを）解析して構造を取り出す

    to examine data according to rules so that its structure can be identified

    The program parses the file and extracts the dates.

    そのプログラムはファイルを解析して日付を抽出する。

よく使う組み合わせ

  • parse a sentence：文を構文解析する
  • parse a JSON file：JSONファイルを解析する

言語学と情報処理で使う。他動詞で parse + 文／データ。
