すし辞書 / write

write

音声は端末の読み上げ機能を使用します。

動詞

  1. 文章や文字を書く

    to put words or symbols on paper or a screen

    Please write your name at the top of the form.

    用紙の上部に名前を書いてください。

    Please write your address on the envelope.

    封筒に住所を書いてください。

  2. 文章・本などを執筆する

    to create a text, book, or other written work

    She is writing a report on urban air pollution.

    彼女は都市の大気汚染についての報告書を執筆している。

  3. 手紙やメッセージを送る

    to communicate with someone by sending a written message

    I wrote to the university to ask about scholarships.

    奨学金について尋ねるため大学に手紙を書いた。

語形変化

よく使う組み合わせ

  • write an essay：小論文を書く
  • write up the findings：調査結果を文章にまとめる
  • write to a colleague：同僚に手紙・メールを書く

write about + テーマ、write to + 人。write upは調査結果などを正式な文章にまとめる意味。過去形・過去分詞はwrote / written。
