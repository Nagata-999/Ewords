すし辞書 / build on

build on

音声は端末の読み上げ機能を使用します。

動詞

  1. （成果・経験を）土台に発展させる

    to use an existing achievement or idea as a foundation for further progress

    The new policy builds on lessons learned during the pilot program.

    新しい政策は試行事業で得た教訓を土台としている。

    The new study builds on earlier research into language learning.

    新しい研究は言語学習に関する先行研究を土台にしている。

    The second experiment builds on the findings of the first.

    二回目の実験は最初の実験結果を土台としている。

  2. （既存の強みを）生かして伸ばす

    to develop a strength or advantage that already exists

    The workshop helps students build on their existing language skills.

    その講習会は生徒がすでに持つ語学力をさらに伸ばすのに役立つ。

よく使う組み合わせ

  • build on previous research：先行研究を土台にする
  • build on success：成功を足がかりに発展させる
  • build on experience：経験を生かす
  • build on existing strengths：既存の強みを生かす

build on + 名詞／経験・成果 は「～を土台として発展させる」。build upon も使える。
