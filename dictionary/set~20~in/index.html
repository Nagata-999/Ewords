すし辞書 / set in

set in

音声は端末の読み上げ機能を使用します。

動詞

  1. （好ましくない状況が）始まって続く

    to begin and become established, especially of an unpleasant condition

    Panic set in when the power failed during the storm.

    嵐の最中に停電すると、パニックが広がり始めた。

よく使う組み合わせ

  • winter sets in：冬が本格的に始まる
  • fatigue sets in：疲労が出始める

主語には寒さ・疲労・不安などの状態が多い。自動詞的に使う。
