filepath

音声は端末の読み上げ機能を使用します。

名詞

  1. ファイルパス；ファイルの保存場所を示す経路

    a sequence of directory names and a filename that specifies where a file is located

    The program could not find the image because the filepath was incorrect.

    ファイルパスが間違っていたため、プログラムは画像を見つけられなかった。

    An absolute filepath begins from a defined root location.

    絶対ファイルパスは決まったルート位置から始まる。

よく使う組み合わせ

  • absolute filepath：絶対ファイルパス
  • relative filepath：相対ファイルパス
  • specify a filepath：ファイルパスを指定する

file path と二語で書く形が一般的。絶対パスは起点を明示し、相対パスは現在の作業場所を基準とする。
