database

音声は端末の読み上げ機能を使用します。

名詞

  1. データベース；体系的に整理されたデータの集合

    an organized collection of information stored so that it can be searched and updated

    Researchers searched the database for studies published after 2020.

    研究者たちは2020年以降に発表された研究をデータベースで検索した。

    The records are stored in a secure database.

    記録は安全なデータベースに保存されている。

    Researchers searched a public database for studies published after 2020.

    研究者たちは2020年以降に発表された研究を公開データベースで検索した。

よく使う組み合わせ

  • search a database：データベースを検索する
  • maintain a database：データベースを管理する
  • online database：オンラインデータベース
  • database system：データベースシステム

database of + 記録・情報。database は整理されたデータの集合で、単一のファイルと同義ではない。
