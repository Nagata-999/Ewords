rollback

音声は端末の読み上げ機能を使用します。

名詞

  1. 変更の取り消し；以前の状態への復帰

    the reversal of a change to restore a system or transaction to an earlier state

    The team initiated a rollback when the update caused login failures.

    更新によってログイン障害が起きたため、チームは変更の取り消しを開始した。

    A database rollback prevents an incomplete transaction from being saved.

    データベースのロールバックは、未完了の取引処理が保存されるのを防ぐ。

よく使う組み合わせ

  • roll back a deployment：配備した更新を元に戻す
  • database rollback：データベースのロールバック
  • rollback plan：切り戻し計画

名詞は rollback（通常一語）、動詞は roll back（二語）。backup からの復元とは同義ではない。
