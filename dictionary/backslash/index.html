名詞

  1. 逆斜線（\）

    the punctuation mark \ used in file paths, commands, and escape sequences

    Use a backslash to escape the quotation mark in this string.

    この文字列では引用符をエスケープするためにバックスラッシュを使う。

    Windows paths often contain backslashes between folder names.

    Windowsのパスではフォルダー名の間にバックスラッシュがよく使われる。

よく使う組み合わせ

  • backslash character：バックスラッシュ文字
  • insert a backslash：バックスラッシュを挿入する
  • double backslash：二重のバックスラッシュ

A backslash (\) differs from a forward slash (/); in programming it often introduces an escape sequence.
