framework

音声は端末の読み上げ機能を使用します。

名詞

  1. 枠組み；骨組み

    a basic structure of ideas, rules, or parts used to organize something

    The framework helps teachers evaluate student writing consistently.

    その枠組みは教員が生徒の作文を一貫して評価するのに役立ちます。

    The researchers developed a framework for comparing education systems.

    研究者たちは教育制度を比較するための枠組みを開発した。

    The researchers developed a framework for comparing education policies.

    研究者たちは教育政策を比較するための枠組みを構築した。

    The framework helps policymakers compare different forms of risk.

    その枠組みは政策立案者が異なる種類のリスクを比較するのに役立つ。

よく使う組み合わせ

  • conceptual framework：概念的枠組み
  • legal framework：法的枠組み
  • regulatory framework：規制の枠組み
  • analytical framework：分析の枠組み
  • framework for decision-making：意思決定の枠組み

framework for + 名詞 は「～のための枠組み」。conceptual framework（概念的枠組み）は研究計画で頻出。
