sandbox

音声は端末の読み上げ機能を使用します。

名詞

  1. 砂場；子供が砂遊びをする場所

    an area filled with sand where children can play

    The children built a castle in the sandbox.

    子供たちは砂場でお城を作った。

    The park has a covered sandbox beside the swings.

    その公園にはブランコの隣に屋根付きの砂場がある。

  2. サンドボックス；隔離された実行・試験環境

    an isolated environment in which software can run or be tested with limited access to other systems

    We tested the plugin in a sandbox before installing it on the main server.

    本番サーバーに導入する前に、プラグインを隔離環境で試した。

    A sandbox reduces the risk that untrusted code will affect the rest of the system.

    サンドボックスは信頼できないコードがほかのシステムに影響する危険を減らす。

よく使う組み合わせ

  • play in a sandbox：砂場で遊ぶ
  • sandbox environment：隔離された試験環境
  • run code in a sandbox：隔離環境でコードを実行する

ITでは「隔離して試す環境」を指す。完全な安全性を保証するという意味ではない。
