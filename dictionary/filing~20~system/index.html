filing system

音声は端末の読み上げ機能を使用します。

名詞

  1. 書類の分類・保管方式

    a method of organizing and storing documents so they can be found when needed

    The clinic introduced an electronic filing system to reduce lost paperwork.

    その診療所は書類の紛失を減らすため電子書類管理方式を導入しました。

    A clear filing system helps staff find contracts quickly.

    分かりやすい書類管理の仕組みは、職員が契約書をすぐ見つける助けになります。

よく使う組み合わせ

  • electronic filing system：電子書類管理方式
  • set up a filing system：書類の整理・保管方式を整える
  • maintain a filing system：書類管理の仕組みを維持する

filing systemは紙の書類にも電子データにも使える。fileは動詞で「書類を整理して保管する」。
