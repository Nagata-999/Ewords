runtime

音声は端末の読み上げ機能を使用します。

名詞

  1. プログラムが実行されている時間；実行時間

    the period or duration during which a program runs

    The algorithm’s runtime increased as the dataset grew.

    データセットが大きくなるにつれてアルゴリズムの実行時間が増えた。

    The test measures the runtime of each sorting method.

    そのテストは各並べ替え手法の実行時間を測定する。

  2. プログラムの実行を支える環境や機構

    the environment or software components that support a program while it executes

    The application requires a compatible Java runtime.

    そのアプリを動かすには互換性のあるJava実行環境が必要だ。

    The runtime manages memory and handles errors.

    実行環境はメモリーを管理し、エラーを処理する。

よく使う組み合わせ

  • runtime environment：実行環境
  • runtime error：実行時エラー
  • measure runtime：実行時間を測定する

Runtime may refer to execution time or to the supporting execution environment; context determines the sense.
