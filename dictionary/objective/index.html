objective

音声は端末の読み上げ機能を使用します。

名詞

  1. （達成すべき）目標；目的

    a specific result that a person or organization aims to achieve

    The project has two main objectives: to reduce waste and lower costs.

    その事業には廃棄物の削減と費用の抑制という二つの主な目標がある。

    Our main objective is to improve students' reading speed.

    私たちの主な目標は生徒の読解速度を上げることです。

    The study’s primary objective is to identify the causes of the decline.

    その研究の主な目的は減少の原因を特定することである。

    The committee set measurable objectives for the first year.

    委員会は初年度に向けて測定可能な目標を設定した。

形容詞

  1. 客観的な；私情に左右されない

    based on facts rather than personal opinions or feelings

    An objective assessment should consider evidence from several sources.

    客観的な評価には複数の情報源からの証拠を考慮すべきだ。

    Try to remain objective when evaluating the evidence.

    証拠を評価するときは客観的であるようにしてください。

    Researchers should use objective criteria when evaluating evidence.

    研究者は証拠を評価する際に客観的な基準を用いるべきである。

よく使う組み合わせ

  • objective evidence：客観的な証拠
  • main objective：主な目標
  • achieve an objective：目標を達成する
  • objective assessment：客観的な評価
  • primary objective：第一の目標
  • remain objective：客観性を保つ

objective は名詞で「目標」、形容詞で「客観的な」。反意語 subjective（主観的な）と対比する。
