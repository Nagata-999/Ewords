すし辞書 / markdown

markdown

音声は端末の読み上げ機能を使用します。

名詞

  1. Markdown形式の軽量な文書記法

    a lightweight markup syntax for formatting plain text

    The project documentation is written in Markdown.

    そのプロジェクトの文書はMarkdownで書かれている。

    Markdown uses asterisks to mark emphasis in many implementations.

    Markdownでは多くの実装でアスタリスクを使って強調を表す。

  2. 値下げ；値下げ額

    a reduction in the listed selling price of a product

    The store announced a markdown on last season’s coats.

    店は昨シーズンのコートの値下げを発表した。

    A steep markdown helped clear the remaining stock.

    大幅な値下げによって残りの在庫が売れた。

よく使う組み合わせ

  • write in Markdown：Markdownで書く
  • Markdown syntax：Markdownの記法
  • a steep markdown：大幅な値下げ

Capitalize Markdown when referring to the text-formatting language; lower-case markdown commonly means a price reduction.
