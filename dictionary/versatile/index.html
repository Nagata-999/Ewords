versatile

音声は端末の読み上げ機能を使用します。

形容詞

  1. 多用途の；応用範囲が広い

    able to be used for many different purposes

    The material is versatile enough for both indoor and outdoor use.

    その素材は屋内でも屋外でも使えるほど用途が広い。

    A smartphone is a versatile tool for language learning.

    スマートフォンは語学学習に多用途な道具です。

  2. 多才な；多方面に対応できる

    able to perform many different tasks or roles well

    A versatile teacher can adapt lessons to different learners.

    多才な教師は異なる学習者に合わせて授業を調整できる。

よく使う組み合わせ

  • ：多用途の道具
  • ：多才な演者
  • ：非常に用途が広い・多才な

versatile は物なら「多用途の」、人なら「多才な」。versatility は名詞。
