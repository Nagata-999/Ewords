actual

音声は端末の読み上げ機能を使用します。

形容詞

  1. 実際の；現実の

    real or true, rather than expected, reported, or imagined

    The actual number of participants exceeded the estimate.

    実際の参加者数は予測を上回った。

    The actual cost was much lower than we expected.

    実際の費用は予想よりずっと低かったです。

  2. 本当の；正確な

    used to emphasize the true identity, amount, or nature of something

    The actual cause of the failure remains unknown.

    失敗の本当の原因は依然として不明だ。

よく使う組み合わせ

  • actual cost：実際の費用
  • actual results：実際の結果
  • actual number：実数；実際の数
  • actual cause：真の原因

actual は「現在の」ではなく「実際の」。現在のは current / present。actually も「現在は」ではなく「実際には」。

語源

Latin agere / actus

actus「行為・現実に行われたこと」に由来し、「実際の」を表すようになった。

  • act / ag：行う・動かす

関連語：act · action · active · activity · react · reaction · interact · interaction
