すし辞書 / already

already

音声は端末の読み上げ機能を使用します。

副詞

  1. すでに；もう

    before now or before the time being discussed

    The committee has already approved the proposal.

    委員会はすでにその提案を承認している。

    I've already sent the file to everyone in the group.

    グループ全員にもうファイルを送りました。

  2. （予想より）もう

    so soon, or sooner than expected

    Is it already time to leave?

    もう出発する時間なのですか。

よく使う組み合わせ

  • already know：すでに知っている
  • have already finished：すでに終えている
  • already in use：すでに使用中の

現在完了形と相性がよい。疑問文では「もう〜なのか」という驚きも表せる。
