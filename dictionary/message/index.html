message

音声は端末の読み上げ機能を使用します。

名詞

  1. 伝言；メッセージ

    information sent or communicated to another person

    Please leave a message if I cannot answer the phone.

    電話に出られなければ伝言を残してください。

    I sent him a message to confirm the meeting time.

    会議時間を確認するため彼にメッセージを送りました。

  2. 主張；伝えたい要点

    the main idea or lesson that a speech, book, or event communicates

    The film’s central message is that trust takes time to build.

    その映画の中心的なメッセージは、信頼を築くには時間がかかるということだ。

よく使う組み合わせ

  • send a message：メッセージを送る
  • key message：主要な主張
  • get the message across：言いたいことを伝える

message は電子的な連絡だけでなく、作品や演説が伝える主張にも使う。get a message across は「趣旨を伝える」。
