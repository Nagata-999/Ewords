entailment

音声は端末の読み上げ機能を使用します。

名詞

  1. （論理・言語学の）含意関係；論理的帰結

    a logical relation in which one statement must be true if another is true

    In logic, entailment means that one statement necessarily follows from another.

    論理学で含意関係とは、一つの命題が別の命題から必然的に導かれることをいう。

よく使う組み合わせ

  • logical entailment：論理的含意
  • semantic entailment：意味論的含意

専門的には logical/semantic entailment。単なる示唆（implication）と区別する。
