すし辞書 / run down

run down

音声は端末の読み上げ機能を使用します。

動詞

  1. （人を車で）ひく

    to hit someone with a vehicle and knock them down

    A cyclist was nearly run down at the busy crossing.

    自転車に乗った人が交通量の多い交差点で危うく車にひかれそうになった。

  2. （人や物を）けなす

    to criticize someone or something unfairly or harshly

    He is always running down his colleagues’ ideas.

    彼はいつも同僚の考えをけなしている。

  3. （電池などが）消耗する

    to gradually lose power or energy

    The battery ran down while the device was in storage.

    装置を保管している間に電池が消耗した。

よく使う組み合わせ

  • be run down by a car：車にひかれる
  • run someone down：人をけなす
  • the battery runs down：電池が消耗する

run + 人 + down は衝突／中傷の二義。run down（自動詞）は電池の消耗も表す。
