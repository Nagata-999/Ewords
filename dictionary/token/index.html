token

音声は端末の読み上げ機能を使用します。

名詞

  1. 認証やアクセスに用いる電子的な識別情報

    a digital value used to verify identity or grant access to a service

    The app issues a temporary token after the user signs in.

    アプリは利用者がサインインすると一時的なトークンを発行する。

    Never share an access token in a public code repository.

    アクセストークンを公開コードリポジトリで共有してはならない。

  2. 言語処理で扱う文字や単語などの単位

    a unit of text that a language-processing system treats as a separate item

    The tokenizer split the sentence into twelve tokens.

    トークナイザーはその文を12個のトークンに分割した。

    A single English word may consist of several tokens.

    英単語一語が複数のトークンから成ることがある。

  3. しるし；象徴として贈る小さな品

    a small object or gesture that represents a feeling or serves as a symbol

    She gave him a book as a token of gratitude.

    彼女は感謝のしるしとして彼に本を贈った。

    The award was a token of the community’s appreciation.

    その賞は地域社会の感謝を表すものだった。

よく使う組み合わせ

  • access token：アクセストークン
  • authentication token：認証トークン
  • a token of appreciation：感謝のしるし

In computing, a token can represent access credentials or a unit of text; in ordinary English, a token is a symbolic gesture.
