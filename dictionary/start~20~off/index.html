すし辞書 / start off

start off

音声は端末の読み上げ機能を使用します。

動詞

  1. ある方法・話題から始める

    to begin an activity by doing something first

    The speaker started off by explaining the purpose of the survey.

    講演者は調査の目的を説明することから始めた。

  2. 出発する・旅を始める

    to begin a journey or movement

    We started off before sunrise to avoid the heat.

    暑さを避けるため日の出前に出発した。

  3. 最初はある状態である

    to be in a particular condition at the beginning of a process

    The discussion started off calmly but soon became heated.

    議論は最初は穏やかだったが、すぐに白熱した。

よく使う組み合わせ

  • start off by explaining：説明することから始める
  • start off early：早く出発する
  • start off well：順調に滑り出す

start off by + 動名詞は文章・発表の構成を説明するとき便利。start off as + 名詞も可能。
