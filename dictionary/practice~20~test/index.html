practice test

音声は端末の読み上げ機能を使用します。

名詞

  1. 模擬テスト；練習用の試験

    a test taken for preparation or practice rather than as the official assessment

    She took a practice test to identify weaknesses in her listening skills.

    彼女はリスニングの弱点を把握するため模擬テストを受けた。

    The practice test follows the same format as the actual exam.

    その模擬テストは本試験と同じ形式に従っている。

よく使う組み合わせ

  • take a practice test：模擬テストを受ける
  • online practice test：オンライン模擬テスト
  • practice test score：模擬テストの得点

practice test は練習目的のテスト。mock exam / mock test も類似表現で、英国英語では mock exam がよく使われる。
