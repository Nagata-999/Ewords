すし辞書 / comparability

comparability

音声は端末の読み上げ機能を使用します。

名詞

  1. 比較可能性；比較に適した程度

    the extent to which two sets of information or things can be meaningfully compared

    Using the same questionnaire improved comparability across the surveys.

    同じ質問票を使うことで調査間の比較可能性が高まった。

よく使う組み合わせ

  • data comparability：データの比較可能性
  • ensure comparability：比較可能性を確保する
  • comparability across studies：研究間の比較可能性

通常は不可算名詞。comparable（比較可能な）と比較する際、測定条件の一貫性が重要。
