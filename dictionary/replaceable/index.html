replaceable

音声は端末の読み上げ機能を使用します。

形容詞

  1. 交換可能な、取り替えられる

    able to be removed and replaced by another part or item

    The device uses a replaceable filter to extend its useful life.

    その装置は交換可能なフィルターを使い、使用寿命を延ばしている。

    The manufacturer supplies replaceable parts for older models.

    メーカーは旧型製品用の交換可能な部品を供給している。

  2. 代わりがきく、代替可能な

    able to be substituted without seriously affecting the result

    Experienced mentors are not easily replaceable in a small school.

    小規模な学校では経験豊かな指導者の代わりを見つけるのは容易ではない。

    Some routine tasks are replaceable by automated systems.

    一部の定型業務は自動化システムで代替できる。

よく使う組み合わせ

  • replaceable parts：交換可能な部品
  • a replaceable battery：交換可能な電池
  • easily replaceable：容易に交換できる

replace（取り替える）+ -able。人について使うと「代わりがきく」という冷淡な含意が生じうる。
