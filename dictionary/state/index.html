すし辞書 / state

state

音声は端末の読み上げ機能を使用します。

名詞

  1. 状態；状況

    the condition of a person or thing at a particular time

    The equipment was in a poor state of repair.

    その設備は修理が必要な状態だった。

    The building is in a poor state of repair.

    その建物は修繕状態がよくありません。

    The treaty places obligations on each member state.

    その条約は各加盟国に義務を課している。

  2. 国家；州

    a country or a political unit within a country

    The federal government works with individual states.

    連邦政府は各州と協力している。

    Each state has its own laws.

    各州には独自の法律があります。

  3. 国家；政府（公的機関として）

    the government and its institutions considered as a whole

    The state has a responsibility to protect basic rights.

    国家には基本的権利を守る責任がある。

動詞

  1. （正式に）述べる；明記する

    to express something clearly in speech or writing

    The guidelines state that applications must be submitted online.

    指針には申請はオンラインで提出しなければならないと明記されている。

    The report states that demand is increasing.

    報告書には需要が増えていると述べられています。

    The report states that the figures are preliminary and may be revised.

    その報告書には、数値は暫定的なもので修正される可能性があると明記されている。

形容詞

  1. 国・州の；公的な

    relating to a government or a particular state

    The museum receives state funding.

    その博物館は州から資金援助を受けている。

よく使う組み合わせ

  • state clearly：明確に述べる
  • state funding：公的資金
  • in a state of shock：ショック状態で
  • member state：加盟国
  • state that：～と明記する
  • state explicitly that ...：…と明確に述べる

動詞 state は say より硬い表現。state that ... は「…と明記する」。 動詞 state は say より改まった表現で、公式文書や調査報告によく使う。

語源

Latin stare / status

Latin status / stare「立つ」に由来し、立っている状態から「状態」や政治的な「国家」へ意味が広がった.

  • sta / stat：立つ

関連語：status · station · stable · establish · distance · instance
