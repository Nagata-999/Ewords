mode

音声は端末の読み上げ機能を使用します。

名詞

  1. 方式；動作モード

    a particular way a device or system operates

    Switch the device to energy-saving mode.

    装置を省エネルギーモードに切り替えてください。

    Switch the phone to silent mode during the meeting.

    会議中はスマートフォンをマナーモードにしてください。

  2. 方法；形態

    a particular manner or form of doing something

    Public transport is the main mode of travel in the city.

    その都市では公共交通機関が主な移動手段である。

  3. （統計学の）最頻値

    the value that occurs most often in a set of data

    In this data set, the mode is seven.

    このデータ集合では最頻値は7である。

よく使う組み合わせ

  • mode of transport：交通手段
  • in silent mode：マナーモードで
  • mode of communication：意思疎通の方法
  • statistical mode：統計上の最頻値

統計では mean（平均値）、median（中央値）、mode（最頻値）を区別する。
