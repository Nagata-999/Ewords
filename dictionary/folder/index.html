すし辞書 / folder

folder

音声は端末の読み上げ機能を使用します。

名詞

  1. （紙の）書類ばさみ；フォルダー

    a folded cover used to hold loose papers together

    Please put the signed forms in the blue folder.

    署名済みの書類を青いフォルダーに入れてください。

    She organized the handouts into separate folders.

    彼女は配布資料を別々のフォルダーに整理した。

  2. （コンピューターの）フォルダー

    a location in a computer file system used to organize files and other folders

    Save the document in the shared folder.

    その文書を共有フォルダーに保存してください。

    I created a new folder for the research data.

    研究データ用に新しいフォルダーを作った。

よく使う組み合わせ

  • a shared folder：共有フォルダー
  • create a folder：フォルダーを作成する
  • a folder of documents：書類の入ったフォルダー

紙の書類入れとデジタルの保存場所の両方に使う。file（個々のファイル）と区別する。
