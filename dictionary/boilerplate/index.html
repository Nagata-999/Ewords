すし辞書 / boilerplate

boilerplate

音声は端末の読み上げ機能を使用します。

名詞

  1. （契約書などの）定型文；決まり文句

    standard wording reused in many documents, often without much change

    The lawyer advised us to read the boilerplate at the end of the agreement.

    弁護士は契約書の末尾にある定型条項も読むよう助言した。

  2. （プログラムの）定型コード

    repeated standard code needed to set up a program or function

    The framework reduces the amount of boilerplate developers have to write.

    そのフレームワークは開発者が書く必要のある定型コードを減らす。

よく使う組み合わせ

  • boilerplate language：定型的な文言
  • a boilerplate clause：定型条項
  • boilerplate code：定型コード

契約書では標準的な文言、プログラミングでは繰り返し使う定型コード。内容を読まずに済ませてよいという意味ではない。
