unit test

音声は端末の読み上げ機能を使用します。

名詞

  1. 単体テスト；個別の関数・部品を調べるテスト

    a software test that checks one small component or function in isolation

    The programmer wrote a unit test for the score calculation function.

    プログラマーは得点計算関数の単体テストを書いた。

    Unit tests passed, but the integration test revealed a database error.

    単体テストは通ったが、結合テストでデータベースのエラーが見つかった。

よく使う組み合わせ

  • write a unit test：単体テストを書く
  • run unit tests：単体テストを実行する
  • unit test coverage：単体テストのカバレッジ

unit は最小の検証対象。integration test（結合テスト）と区別する。
