すし辞書 / keyboard

keyboard

音声は端末の読み上げ機能を使用します。

名詞

  1. （パソコンなどの）キーボード

    a set of keys used to enter letters, numbers, and commands into a computer or device

    I use an external keyboard with my laptop.

    私はノートパソコンに外付けキーボードを使っている。

    The keyboard stopped working after water spilled on it.

    水をこぼした後、そのキーボードは動かなくなった。

  2. 鍵盤；鍵盤楽器

    the row or arrangement of keys on a piano or electronic musical instrument

    He learned the melody on an electronic keyboard.

    彼は電子キーボードでその旋律を覚えた。

よく使う組み合わせ

  • a wireless keyboard：無線キーボード
  • keyboard shortcuts：キーボードショートカット
  • an electronic keyboard：電子鍵盤楽器

keyboard は入力装置と楽器の鍵盤の両方に使う。keyboard shortcut はキー操作による近道。
