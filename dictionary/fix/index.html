fix

音声は端末の読み上げ機能を使用します。

動詞

  1. （壊れた物を）修理する

    to repair something that is broken or not working properly

    The technician fixed the projector before the presentation began.

    技術者は発表が始まる前にプロジェクターを修理した。

    Can you fix the loose handle on this door?

    このドアの緩んだ取っ手を直してもらえますか。

  2. （問題・誤りを）解決する；修正する

    to correct an error or deal with a problem so that it no longer causes trouble

    The developers released an update to fix the login problem.

    開発者たちはログインの問題を修正する更新版を公開した。

    Changing the timetable alone will not fix the shortage of teachers.

    時間割を変えるだけでは教員不足は解決しない。

よく使う組み合わせ

  • fix a problem：問題を解決する
  • fix a broken chair：壊れた椅子を修理する
  • fix a software bug：ソフトウェアの不具合を修正する

fix は修理と問題解決の両方で使う。fix a date は「日取りを決める」という別の意味。
