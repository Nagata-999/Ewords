すし辞書 / compile

compile

音声は端末の読み上げ機能を使用します。

動詞

  1. 資料・情報を集めてまとめる；編集する

    to collect information from different sources and organize it into a document or list

    Researchers compiled data from twelve separate studies.

    研究者たちは12件の別々の研究からデータを集めてまとめた。

    The team compiled the survey results into a report.

    チームは調査結果を報告書にまとめました。

  2. （プログラムを）コンパイルする

    to translate source code into a form that a computer can execute

    The program failed to compile because of a syntax error.

    構文エラーのため、そのプログラムはコンパイルできなかった。
