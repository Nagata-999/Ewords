search

音声は端末の読み上げ機能を使用します。

動詞

  1. 探す；検索する

    to look carefully for something or to use a tool to find information

    Researchers searched the database for similar studies.

    研究者たちは類似の研究をデータベースで検索した。

    I searched the website for information about the course.

    その講座についての情報をウェブサイトで検索しました。

名詞

  1. 捜索；検索

    an attempt to find someone, something, or information

    A quick search revealed several relevant articles.

    簡単に検索すると、関連する記事がいくつか見つかった。

よく使う組み合わせ

  • search for information：情報を検索する
  • search results：検索結果
  • search a database：データベースを検索する

search for + 探す対象、search + 場所・データベース。「search information」より search for information が自然。
