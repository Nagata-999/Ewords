host

音声は端末の読み上げ機能を使用します。

名詞

  1. 主催者；招待客を迎える人

    a person or organization that welcomes guests or organizes an event

    The host welcomed delegates from twelve countries.

    主催者は12か国からの代表者を歓迎した。

  2. 宿主；寄生生物などを受け入れる生物

    an organism in or on which another organism lives

    Some viruses can infect more than one animal host.

    一部のウイルスは複数の動物宿主に感染することがある。

動詞

  1. （催しを）主催する；（客を）もてなす

    to organize an event or receive guests

    The university will host an international conference in November.

    その大学は11月に国際会議を主催する。

よく使う組み合わせ

  • host a conference：会議を主催する
  • host country：開催国；受入国
  • animal host：動物宿主

host は名詞と動詞で使う。host a meeting は「会議を主催する」。生物学では「宿主」。
