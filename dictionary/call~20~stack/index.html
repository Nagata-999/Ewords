すし辞書 / call stack

call stack

音声は端末の読み上げ機能を使用します。

名詞

  1. 呼び出し履歴を保持する構造

    A last-in, first-out data structure that tracks active function calls and their execution contexts.

    The error message included a call stack showing where the program failed.

    エラーメッセージにはプログラムが失敗した場所を示す呼び出し履歴が含まれていた。

    Deep recursion can exhaust the call stack and crash a program.

    再帰呼び出しが深すぎると呼び出しスタックを使い切り、プログラムが停止することがある。

よく使う組み合わせ

  • call stack trace：呼び出しスタックの追跡情報
  • call stack overflow：呼び出しスタックのオーバーフロー
  • inspect the call stack：呼び出しスタックを調べる

Also called the execution stack; stack traces are representations of call-stack frames.
