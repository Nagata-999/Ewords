code review

音声は端末の読み上げ機能を使用します。

名詞

  1. コードレビュー；ソースコードの確認・検討

    an examination of source code to find defects and improve its quality, often by another developer

    The team found a security flaw during code review.

    チームはコードレビュー中にセキュリティ上の欠陥を発見した。

    A careful code review can make a program easier to maintain.

    丁寧なコードレビューはプログラムの保守を容易にする。

よく使う組み合わせ

  • conduct a code review：コードレビューを実施する
  • peer code review：開発者同士のコードレビュー
  • code review feedback：コードレビューでの指摘

review は単なる動作確認ではなく、設計・可読性・安全性などの検討も含む。
