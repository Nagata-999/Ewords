set

音声は端末の読み上げ機能を使用します。

動詞

  1. 置く；位置を定める

    to put something in a chosen place or position

    He set the cups carefully on the tray.

    彼はカップを慎重にトレーに置きました。

  2. 時刻・温度などを設定する

    to adjust a device or control to a chosen value

    Set the alarm for six thirty.

    目覚ましを6時半に設定してください。

  3. 日程・規則・基準などを定める

    to decide on a date, rule, limit, or standard

    The committee set a deadline for applications.

    委員会は応募の締め切りを定めました。

  4. 物語などの舞台を設定する

    to place the events of a story in a particular time or location

    The novel is set in a quiet fishing village.

    その小説は静かな漁村を舞台にしています。

  5. 太陽などが沈む

    to move below the horizon as seen from a place on Earth

    We watched the sun set behind the hills.

    私たちは丘の向こうに日が沈むのを見ました。

  6. 固まる；凝固する

    to become firm or solid after being soft or liquid

    Leave the jelly in the fridge until it sets.

    ゼリーが固まるまで冷蔵庫に入れておいてください。

名詞

  1. 一組；一式；集合

    a group of things treated as belonging together

    She bought a set of six bowls.

    彼女は6個組のボウルを買いました。

  2. 映画などの撮影セット；舞台装置

    the scenery and surroundings prepared for filming or a stage performance

    The crew rebuilt the kitchen set for the next scene.

    スタッフは次の場面のために台所のセットを組み直しました。

  3. テニスなどのセット

    one of the main divisions of play in sports such as tennis

    He won the first set but lost the match.

    彼は第1セットを取りましたが、試合には負けました。

形容詞

  1. 決まった；用意ができた

    fixed in advance or ready for a planned action

    We follow a set routine every morning.

    私たちは毎朝決まった手順に従っています。

熟語・表現

  • set up：設立する；組み立てる
  • set aside：取っておく；脇へ置く
  • set off：出発する；引き起こす

よく使う組み合わせ

  • set a deadline
  • set an alarm
  • set an example

使い方・語法

過去形・過去分詞はset、進行形はsetting。置く・設定する動詞、集まりの名詞、決まった・準備できた状態の形容詞を区別する。set something for + 時刻、set something to + 値などの形で使う。
