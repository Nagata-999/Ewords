source code

名詞

  1. ソースコード；人が読めるプログラムの記述

    instructions for a computer program written in a programming language before or apart from their execution

    The students examined the source code to understand how the game worked.

    生徒たちはゲームの仕組みを理解するためにソースコードを調べた。

    The developer fixed the bug by changing three lines of source code.

    開発者はソースコードの3行を変更して不具合を修正した。

よく使う組み合わせ

  • read source code：ソースコードを読む
  • modify source code：ソースコードを修正する
  • open-source code：公開されたソースコード

source code は開発者が書くコード。実行形式の machine code や object code と区別される。
