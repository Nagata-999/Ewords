load balancer

音声は端末の読み上げ機能を使用します。

名詞

  1. 負荷分散装置；処理を複数のサーバーに振り分ける仕組み

    a device or service that distributes incoming requests across multiple servers

    The load balancer sent new requests to the least busy server.

    負荷分散装置は新しい要求を最も空いているサーバーに振り分けた。

    A load balancer can keep a website available when one server goes offline.

    負荷分散装置があれば、一台のサーバーが停止してもウェブサイトを利用可能に保てることがある。

よく使う組み合わせ

  • application load balancer：アプリケーション用負荷分散装置
  • configure a load balancer：負荷分散装置を設定する
  • load balancer health check：負荷分散装置による稼働確認

load balancing は負荷分散という処理、load balancer はそれを行う装置・サービス。
