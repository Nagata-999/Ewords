すし辞書 / instantiate

instantiate

音声は端末の読み上げ機能を使用します。

動詞

  1. （クラスなどから）インスタンスを生成する

    to create a particular object from a class or template in a program

    The program instantiates a new object for each player.

    プログラムはプレーヤーごとに新しいオブジェクトを生成する。

    This function instantiates the model only when it is needed.

    この関数は必要になったときにだけモデルのインスタンスを生成する。

  2. 抽象的な考えを具体的な形にする

    to give a concrete example or physical form to an abstract idea

    The pilot project instantiates the principles described in the report.

    試験事業は報告書に示された原則を具体化している。

    Each classroom activity instantiates a different approach to learning.

    各授業活動は学習への異なる取り組み方を具体的に示している。

よく使う組み合わせ

  • instantiate an object：オブジェクトを生成する
  • instantiate a class：クラスからインスタンスを生成する
  • instantiate a model：モデルを具体化する／インスタンス化する

In software engineering, instantiate is commonly used with class and object; in academic prose it can mean make an abstract idea concrete.
