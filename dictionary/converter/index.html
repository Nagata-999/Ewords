converter

音声は端末の読み上げ機能を使用します。

名詞

  1. 変換器；変換装置

    a device that changes one form of energy, signal, or material into another

    The solar system uses a converter to manage the electrical output.

    その太陽光発電システムは電力出力を制御するために変換装置を使っている。

  2. （ファイルなどの）変換ソフト

    software that changes data from one format into another

    The file converter preserved the images but changed the formatting.

    ファイル変換ソフトは画像を保持したが書式を変更してしまった。

よく使う組み合わせ

  • file converter：ファイル変換ソフト
  • power converter：電力変換装置
  • signal converter：信号変換器
  • voltage converter：電圧変換器

convert A into/to B（AをBに変換する）から派生。装置にもソフトウェアにも使う。
