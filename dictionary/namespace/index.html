namespace

音声は端末の読み上げ機能を使用します。

名詞

  1. 名前空間；識別子の衝突を避けるための範囲

    a defined context in which names identify distinct variables, functions, or other objects

    Putting the functions in a separate namespace prevents naming conflicts.

    関数を別の名前空間に置くことで、名前の衝突を防げる。

    Two modules can use the same function name if their namespaces differ.

    名前空間が異なれば、二つのモジュールで同じ関数名を使える。

よく使う組み合わせ

  • global namespace：グローバル名前空間
  • namespace collision：名前空間内の名前の衝突
  • declare a namespace：名前空間を宣言する

scope（変数が参照できる範囲）と関連するが、namespace は名前を区別する仕組みに重点がある。
