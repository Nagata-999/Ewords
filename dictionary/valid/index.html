valid

音声は端末の読み上げ機能を使用します。

形容詞

  1. 妥当な；有効な

    based on sound reasoning or evidence and therefore acceptable or convincing

    That is a valid criticism of the study.

    それはその研究に対する妥当な批判です。

    A measure can be reliable without being valid.

    測定法は信頼性が高くても妥当とは限らない。

  2. （期限内で）有効な

    officially acceptable or legally effective for a specified period

    The passport must be valid for at least six months after arrival.

    パスポートは到着後少なくとも6か月間有効でなければならない。

    The ticket is valid for twenty-four hours after its first use.

    そのチケットは最初に使用してから24時間有効だ。

    The discount code is valid only for purchases made this week.

    その割引コードは今週中の購入に限り有効だ。

よく使う組み合わせ

  • valid conclusion：妥当な結論
  • valid measure：妥当な測定方法
  • valid argument：妥当な議論
  • valid until ...：…まで有効な
  • valid for twenty-four hours：24時間有効な
  • remain valid：引き続き有効である

valid は「論理的に妥当な」と「期限・法的に有効な」の両方に使う。 valid argument は論理的に妥当な議論、valid ticket は期限・条件上有効な切符。

語源

Latin valere / validus

validus / valere「強い」に由来し、有効な意味へ発展した。

  • val：強い・価値がある

関連語：value · valuable · validity · evaluate · equivalent
