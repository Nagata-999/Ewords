application

名詞

  1. 申請；応募

    a formal request for permission, admission, or a position

    Submit your application before the scholarship deadline.

    奨学金の締め切り前に申請書を提出してください。

    The deadline for university applications is next Friday.

    大学出願の締め切りは次の金曜日です。

  2. 応用；適用

    the practical use of an idea, method, or rule

    The study explores the application of AI to language learning.

    その研究はAIの語学学習への応用を探っている。

  3. アプリケーション；ソフトウェア

    a program designed for a particular task

    The application stores practice results on the device.

    そのアプリは練習結果を端末に保存する。
