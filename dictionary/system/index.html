すし辞書 / system

system

音声は端末の読み上げ機能を使用します。

名詞

  1. 制度；仕組み

    an organized set of connected parts or rules

    The country has a national health-care system.

    その国には国の医療制度があります。

    The new system allows students to track their learning progress.

    新しい仕組みにより、生徒は学習の進捗を把握できる。

    A secure system should limit access to sensitive information.

    安全なシステムは機密情報へのアクセスを制限すべきである。

  2. （機器などの）システム；装置群

    a set of connected parts that work together to perform a function

    The monitoring system detected the leak immediately.

    監視システムは漏れをすぐに検知した。

よく使う組み合わせ

  • computer system：コンピューターシステム
  • operating system：オペレーティングシステム
  • education system：教育制度
  • a system of rules：規則の体系

System can describe organized rules or institutions as well as connected technical components.
