system call

音声は端末の読み上げ機能を使用します。

名詞

  1. システムコール；プログラムからOSの機能を呼び出す操作

    a request made by a program to the operating system for a service such as opening a file

    The program uses a system call to read data from the disk.

    そのプログラムはディスクからデータを読み取るためにシステムコールを使う。

よく使う組み合わせ

  • make a system call：システムコールを行う
  • system call interface：システムコールのインターフェース

A system call crosses from application code into operating-system services; it is not simply any function call.
