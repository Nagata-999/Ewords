file extension

音声は端末の読み上げ機能を使用します。

名詞

  1. ファイル拡張子

    a short group of characters at the end of a filename, often indicating the file format

    The file extension tells the computer which application may open the document.

    拡張子は、その文書を開ける可能性のあるアプリをコンピューターに示す。

    Changing the file extension does not convert the file to another format.

    拡張子を変更してもファイルが別の形式に変換されるわけではない。

よく使う組み合わせ

  • change a file extension：ファイル拡張子を変更する
  • hidden file extension：非表示のファイル拡張子
  • recognized file extension：認識されるファイル拡張子

例：.pdf、.jpg。拡張子は形式の手がかりだが、実際のファイル内容を保証するものではない。
