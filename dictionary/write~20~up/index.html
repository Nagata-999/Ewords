すし辞書 / write up

write up

音声は端末の読み上げ機能を使用します。

動詞

  1. （メモや調査を）報告書などにまとめる

    to prepare a complete written account from notes or research

    Please write up the interview notes by Friday.

    金曜日までにインタビューのメモを報告書にまとめてください。

  2. （出来事などを）記事として書く

    to describe an event or subject in a published account

    The journalist wrote up the findings for a local newspaper.

    その記者は調査結果を地元紙の記事にまとめた。
