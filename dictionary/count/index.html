count

音声は端末の読み上げ機能を使用します。

動詞

  1. （数を）数える

    to determine the number of people or things in a group

    The volunteers counted the birds visiting the wetland each morning.

    ボランティアたちは毎朝その湿地を訪れる鳥の数を数えた。

    Count the number of words in your essay before submitting it.

    提出する前に作文の語数を数えてください。

  2. 重要である；価値がある

    to be important or to have an effect on a result

    Every vote counts in a close election.

    接戦の選挙では一票一票が重要だ。

    What counts is how well the proposal addresses the problem.

    大切なのは、その提案が問題にどれだけ適切に対処しているかだ。

よく使う組み合わせ

  • count the number of：〜の数を数える
  • count on someone：人を頼りにする
  • every vote counts：一票一票が重要だ

count は「数える」のほか「重要である」。count on は「頼る」で、単独の count とは意味が異なる。
