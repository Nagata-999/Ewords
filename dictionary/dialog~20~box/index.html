dialog box

音声は端末の読み上げ機能を使用します。

名詞

  1. ダイアログボックス；操作を求める小窓

    a small window on a computer screen that displays information or asks the user to make a choice

    A dialog box appeared asking whether I wanted to save the changes.

    変更を保存するか尋ねるダイアログボックスが表示された。

    Read the warning in the dialog box before clicking OK.

    OKを押す前にダイアログボックスの警告を読んでください。

よく使う組み合わせ

  • open a dialog box：ダイアログボックスを開く
  • confirmation dialog box：確認ダイアログ
  • close a dialog box：ダイアログボックスを閉じる

dialog は米国式、dialogue は英国式で一般的。コンピューター用語では dialog box が広く使われる。
