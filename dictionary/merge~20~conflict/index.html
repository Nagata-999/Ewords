merge conflict

音声は端末の読み上げ機能を使用します。

名詞

  1. 複数の変更を自動的に統合できない状態

    a conflict that occurs when a version-control system cannot automatically combine changes

    Two developers edited the same line, causing a merge conflict.

    二人の開発者が同じ行を編集したため、マージコンフリクトが発生した。

    Resolve the merge conflict before completing the pull request.

    プルリクエストを完了する前にマージコンフリクトを解消してください。

よく使う組み合わせ

  • resolve a merge conflict：マージコンフリクトを解消する
  • merge conflict marker：競合箇所を示すマーカー
  • encounter a merge conflict：マージコンフリクトに遭遇する

A merge conflict requires review of competing changes; choosing one side blindly can discard useful work.
