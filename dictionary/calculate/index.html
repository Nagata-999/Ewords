calculate

音声は端末の読み上げ機能を使用します。

動詞

  1. 〜を計算する；算出する

    to find a number by using mathematical operations

    The team calculated the average cost per household.

    チームは1世帯当たりの平均費用を算出した。

    Calculate the average score for each class.

    各クラスの平均点を計算してください。

  2. 〜を見積もる；予測する

    to estimate something using available information

    It is difficult to calculate the long-term risks.

    長期的なリスクを見積もるのは難しい。
