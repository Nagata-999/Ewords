すし辞書 / own up

own up

音声は端末の読み上げ機能を使用します。

動詞

  1. 自分の誤り・責任を認める

    to admit that one has done something wrong or is responsible for it

    The student owned up to copying part of the assignment.

    その生徒は課題の一部を写したことを認めた。

よく使う組み合わせ

  • own up to a mistake：間違いを認める
  • own up to what happened：何が起きたか正直に話す
  • finally own up：ついに非を認める

own up to + 名詞・動名詞。「責任を認める」の意味で、単なる admit より口語的。
