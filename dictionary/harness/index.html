harness

音声は端末の読み上げ機能を使用します。

動詞

  1. （力・資源・技術などを）活用する

    to control and use a resource or force for a particular purpose

    The city plans to harness solar energy to power public buildings.

    市は公共施設の電力に太陽エネルギーを活用する計画だ。

名詞

  1. （動物用の）引き具；（安全用の）装着具

    a set of straps used to control an animal or secure a person

    All climbers must wear a safety harness.

    登山者は全員、安全ハーネスを着用しなければならない。

  2. （ソフトウェアの）テスト実行を支える仕組み

    a set of tools or code used to run and check software tests

    The engineers built a test harness to automate repeated checks.

    技術者たちは反復的な検査を自動化するテスト用の仕組みを作った。

よく使う組み合わせ

  • harness renewable energy：再生可能エネルギーを活用する
  • wear a safety harness：安全ハーネスを着用する
  • a test harness：テスト実行用の仕組み

harness the power of A は「Aの力を活用する」。名詞の harness は馬具・安全装具やIT分野の test harness にも使う。
