installation

音声は端末の読み上げ機能を使用します。

名詞

  1. （機器などの）設置；据え付け

    the process of putting equipment in place so it can be used

    Installation of the solar panels will begin next month.

    太陽光パネルの設置は来月始まる。

  2. （ソフトウェアの）インストール

    the process of putting a program onto a computer or device

    The installation failed because there was not enough storage space.

    保存容量が不足していたため、インストールに失敗した。

よく使う組み合わせ

  • equipment installation：機器の設置
  • software installation：ソフトウェアのインストール
  • installation instructions：設置・導入手順

install（設置する・導入する）の名詞形。installation of A は「Aの設置・導入」。
