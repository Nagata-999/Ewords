すし辞書 / number

number

音声は端末の読み上げ機能を使用します。

名詞

  1. 番号；識別用の数字

    a figure or series of figures used to identify something

    Please write your student number on the answer sheet.

    解答用紙に学籍番号を書いてください。

    Write your student number at the top of the page.

    ページ上部に学籍番号を書いてください。

  2. 数；数量

    an amount expressed as a count

    The number of applicants increased this year.

    今年は志願者の数が増えた。

動詞

  1. 番号を付ける

    to assign numbers to items in a sequence

    Number the pages before you submit the report.

    報告書を提出する前にページ番号を付けてください。

よく使う組み合わせ

  • a large number of：多数の
  • the number of students：生徒の人数
  • number the pages：ページに番号を付ける

a number of + 複数名詞は複数扱い、the number of + 複数名詞は単数扱いが基本。

語源

Latin numerus

Latin numerus「数」に由来し、Old French を経て英語に入った。

  • numer：数

関連語：numerous · enumerate
