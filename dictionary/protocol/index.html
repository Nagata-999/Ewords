protocol

音声は端末の読み上げ機能を使用します。

名詞

  1. 手順；規約；プロトコル

    an official procedure or set of rules

    All participants followed the same research protocol.

    参加者全員が同じ研究手順に従った。

    All participants followed the same experimental protocol.

    参加者全員が同じ実験手順に従った。

    The laboratory revised its protocol for handling biological samples.

    研究室は生体試料の取り扱い手順を改訂した。

    All laboratories followed the same testing protocol.

    すべての研究室が同じ検査手順に従った。

    The hospital revised its emergency protocol after the power outage.

    その病院は停電後、緊急時の対応手順を改訂した。

  2. （コンピューター間の）通信規約

    a set of rules that governs how devices exchange data

    The devices use a standard protocol to exchange data securely.

    その機器は安全にデータを交換するため標準的な通信規約を使う。

よく使う組み合わせ

  • research protocol：研究手順
  • follow a protocol：定められた手順に従う
  • safety protocol：安全手順
  • communication protocol：通信規約
  • protocol for handling samples：試料の取り扱い手順
  • emergency protocol：緊急時の対応手順

研究・外交・通信などで「定められた手順・規約」。 research protocol は研究手順、communication protocol は通信規約。
