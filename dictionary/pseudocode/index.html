pseudocode

音声は端末の読み上げ機能を使用します。

名詞

  1. 疑似コード；処理手順をプログラム風に記したもの

    an informal description of an algorithm using language and programming-like structures without strict syntax

    Write pseudocode before choosing a programming language.

    プログラミング言語を選ぶ前に疑似コードを書いてください。

    The pseudocode helped the class compare two search algorithms.

    その疑似コードはクラスが二つの探索アルゴリズムを比較する助けになった。

よく使う組み合わせ

  • write pseudocode：疑似コードを書く
  • pseudocode outline：疑似コードによる概略
  • convert pseudocode into code：疑似コードを実際のコードに書き換える

pseudocode は通常、特定の言語でそのまま実行できるコードではない。手順や論理を整理するために用いる。
