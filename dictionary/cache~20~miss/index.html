cache miss

音声は端末の読み上げ機能を使用します。

名詞

  1. キャッシュミス；必要なデータがキャッシュにないこと

    an event in which requested data is not found in a cache

    A cache miss forced the processor to fetch data from main memory.

    キャッシュミスのため、プロセッサーは主記憶からデータを取得しなければならなかった。

    The team measured the cache miss rate during the performance test.

    チームは性能試験中にキャッシュミス率を測定した。

よく使う組み合わせ

  • cache miss rate：キャッシュミス率
  • reduce cache misses：キャッシュミスを減らす
  • a cache miss occurs：キャッシュミスが発生する

cache miss は要求したデータがキャッシュにない状態。cache hit はデータがキャッシュにある状態。
