# すしTRAIL 管理者プレビュー

管理者ページの「RPGを試す」から利用する横スクロール自動戦闘RPG。現行SushiAvatarV2の右向き姿と、端末に装備した見た目を使用する。背景はCanvasの描き込んだ背景アトラスと大気のスクロール、プレイヤーと装備はSVG、敵は透過の描画アトラスを使用する。

- 10ステージ。雑魚戦は自動反復、ボスは任意挑戦。ボスの初回勝利で次のステージと仲間を解放。
- 装備は剣・盾・頭・胴・足・アクセサリ、4レアリティ、ランダムドロップ、付加効果、ゴールドで20段階強化。バッグ上限96個で未装備の弱い装備を素材化。
- 初期ペットは現行アバターのペットを反映（未設定はこねこ）。試作用召喚チケット3枚でペット召喚。実際のジェム・アバターガチャの所有物を変更しない。
- 初回起動後のすし単20問正解ごとに宝箱・チケット1枚。既存の正解イベントストリームを読み取り、基準値・受取ブロック数を保存して再読み込みの重複付与を防ぐ。
- 学習宝箱はレア55%、エピック38%、レジェンド7%。通常敵32%ドロップ、ボスはレア以上を必ずドロップ。
- 召喚はすし丸30%、ぷるり30%、こりゅう25%、きつね13%、フェニックス2%。重複は試作用60G。
- 射手、癒し手、魔導士はボス初回討伐数2・5・8で参加。

親の管理者ページで認証が成功した場合だけ、nonceとiframeのsourceを照合して初期化する。iframeはallow-scriptsのみのsandboxで、API通信と実際のlocalStorageへのアクセスを許可しない。親ページが専用キーsushitan_rpg_lab_v2へ進行を保存する。普段のジェム、実績、同期ID・PIN・管理者トークンをiframeへ渡さない。RPGの戦闘・保存でDB通信は発生しない。

管理者テスト: 20問正解の再現、雑魚戦10分の早送り、任意ステージの開放、専用進行の初期化。これらはすべて試作用データだけを変更する。

画面を非表示にした時・別タブの時は戦闘停止。オフライン収益・端末間のRPG進行同期はこのプレビューには含まない。全ステージの演出、バランス、ペットガチャ運用を確認してから一般公開の仕様を決める。

検証: node --test tests/idle-rpg.test.cjs。Chromeでtests/idle-rpg-browser.cjsを実行（PLAYWRIGHT_MODULE、CHROME_PATHを指定）。管理者ログインはモック、外部書き込みは遮断し、学習・装備・ボス・召喚・保存・ログアウトとPC/390px/320pxの画面を確認する。

## 戦闘・成長 v2

通常戦は3〜5匹、ボスには護衛2匹が参加。初期HP58・攻撃10・防御1で、初期群れの総攻撃3ターン目に敗北する。倒した敵のドロップと経験値は敗北しても保持。敵の個別撃破に80%の装備ドロップ（最初の個別撃破は確定）を付け、全滅待ちの進行停止を防ぐ。成長の中心は6部位の装備とランダム追加効果、レベル上昇の基本能力は控えめ。

狙う敵を選び、6秒再使用の薙ぎ払い（全体攻撃＋短い妨害）、5秒再使用のガード（2.1秒間75%軽減）、8秒再使用の回復薬（HP45%、3個）を使える。敵の総攻撃ゲージを見てガードする。初期装備でも薙ぎ払い＋ガードを使用すると初期群れを突破できる。装備バッグは部位ごとに表示し、現在装備との比較値を示す。

v1の試作進行は保持したままv2の専用保存キーで新規開始する。アバターの右腕のSVGグループ内へ剣を描き、同じ腕の回転・移動で手と剣を動かす。盾は左腕に接続し、兜・胴装備・足装備の品質を描画へ反映する。

背景・敵はImageGen内蔵ツールで作ったアトラスをWebP形式へ最適化。生成仕様はassets/PROMPTS.md。API料金のかかる外部画像サービスは使わない。ゲームのDB処理追加なし。
