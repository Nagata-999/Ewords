# 単語表示の見切れ対策
すし単・しの単・あんとに単の選択肢は絶対座標で配置され、低い表示領域では重複し得ました。learning-paths.cssの最小高さ100pxも縮小を許していました。
共通レイアウトで3ゲームの選択肢を2列の自動高さグリッドにし、長い語句を折り返します。問題・スコア・操作欄は縮めず、画面が足りない場合はゲーム領域をスクロールします。dvh非対応時はvhで高さを確保します。共有ローダーの版を更新しました。
他ゲームでは、シャリ単の移動式選択肢、ブロックブラすしのダイアログ式出題、および共通ルート・固定オーバーレイ指定を確認しました。これらに単語ゲーム専用グリッドは適用しません。
検証: ChromeとEdgeの実ブラウザエンジンで3ゲーム×6表示サイズ（1366×768、1024×600、800×450、640×360、390×844、320×568）に長い8選択肢を置き、重なり・文字の欠け・横はみ出し・スクロール可能性を検査。テストは外部サービスへアクセスしないレイアウト用fixtureです。低解像度で拡大時相当のCSS表示領域を検証していますが、OS表示倍率・実ブラウザズームそのものの再現ではありません。Firefox・Safariの実機確認、全ゲームのプレイ検証は未実施です。
