# すし単・すしイディオムのランキングと復習機能

## 適用順序

1. 既存サイトが使っているSupabaseプロジェクトで **SQL Editor → New query** を開き、`daily-ranking.sql` の全文を実行します。
2. 成功したら、サイトの以下の2ファイルを差し替えます。
   - `sushitan.html`
   - `sushi_idiom (1).html`（ファイル名の半角スペースと括弧もそのまま）
3. ページを再読み込みし、通常プレイを終えてスコアを保存します。

SQLを先に適用してください。HTMLだけ差し替えると、新しい保存関数が存在せず、スコアの保存・TODAY取得が失敗します。

既存の `scores` テーブルと `save_high_score` 関数は置き換えません。既存の単語JSON、音声、画像も引き続き使用します。HTML単体を別フォルダに移すと、それらの相対パスが見つからない場合があります。

## 変更内容

- **ALL TIME**：これまでの通算最高点を保持。
- **TODAY**：名前・ゲーム・レベル・日付ごとの最高点を別テーブルに保持。通算最高点を超えていないプレイでも保存。
- 日付はサーバーの日本時間で決定。0時以降に保存された記録は新しい日の記録になります。
- 同名は1件。同点の場合は最大コンボ、正答率の順に比較。名前の全角・半角、英字の大小、余分な空白は日別ランキングでは同一として扱います。
- すし単はALL・Lv.1〜4のレベル区分を維持し、ランキング画面と結果画面にTODAY／ALL TIMEを追加。
- すし単の間違えた単語はこのブラウザに自動保存。全レベルの苦手単語を一覧表示し、時間制限なしで復習。同じ単語に2回連続正解すると削除。間違えたらその単語の連続正解をリセット。
- 復習は1語だけでも継続し、終了ボタンでも終了可能。復習はランキング・通算ベスト・累計スコアへ加算しません。
- すしイディオムの1種類だけの復習で止まる処理と、復習スコアで個人ベストが更新される処理も修正。

## 過去のTODAYについて

以前の方式で保存されなかった「通算ベストより低いプレイ」は復元できません。TODAYはこの変更の適用後に保存するプレイから蓄積します。既存の通算記録はそのまま残ります。

## 確認したこと

ローカルのPostgreSQL環境（PGlite）でSQLを実行し、通算1000点の人が今日300点を保存できること、同日の低い点で上書きされないこと、日付切替、日本時間0時境界、名前の正規化、レベルの分離、匿名RPCの権限、保存失敗時のロールバック、SQLの再実行を確認しました。

両HTMLのスクリプトを実行して、復習の保存と2回正解・ミス時のリセット、1語の反復、タイマーとランキングへの非加算、通常プレイへの復帰、ブラウザ保存失敗時の処理、ランキング切替時の非同期応答順序を確認しました。

本番Supabaseの管理権限には接続していないため、本番関数との実接続と実画面での試遊は未確認です。既存の `save_high_score` がHTMLから使っている5引数を受け取ることが前提です。

Supabase関数の参考：[公式ドキュメント](https://supabase.com/docs/guides/database/functions)
