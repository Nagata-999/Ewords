IELTS Readingの練習方法

IELTS Academic Readingは、3つの長文と合計40問に60分で取り組む試験です。このページでは、1 Passageずつの短時間練習と、3 Passageを通したフルテストの両方ができます。問題はすべて、すし単で作成したオリジナル教材です。

1 Passageずつ練習する

上のLibraryから問題を選ぶと、1 Passageを20分の目安で練習できます。1問ごとに採点できるため、授業の一部や短い自習時間にも利用できます。

解答後に根拠を確認する

正解・不正解だけで終わらず、本文中の根拠、設問との言い換え、日本語解説を確認できます。特にNOT GIVENは、本文に反対情報があるのか、判断材料そのものがないのかを区別してください。

本番と同じ60分で解く

Set 5以降は、3 Passage・40問・約2,100語で構成したフルテストです。途中で答えを確認せず、60分を計って最後まで進めると、本番に近い時間配分を練習できます。

問題を印刷して使う

「問題を読む・印刷する」から、問題用ページと解答・根拠ページを別々に開けます。紙に線を引きながら解きたい場合や、授業・家庭学習で配布する場合に利用してください。

収録している主な設問形式

TRUE / FALSE / NOT GIVEN、YES / NO / NOT GIVEN、見出し選択、段落情報照合、選択問題、要約・文完成などを収録しています。設問文と本文では同じ意味が別の表現で示されることが多いため、単語の一致だけでなく、文全体の意味を照合することが大切です。

  1. 最初は1 Passageを20分で解く
  2. 採点後、間違えた問題の根拠まで戻る
  3. 本文と設問の言い換えを記録する
  4. 慣れたら3 Passageを60分で通して解く
