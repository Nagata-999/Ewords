すし暗範囲指定・苦手単語復習

すし暗

遊び方・練習内容

約2,000語から番号の範囲を指定し、英単語の意味を4択で確認します。問題数は10問・20問・50問・全問から選べます。学校や自分の単語帳と番号が同じとは限らないため、先にすし単の単語一覧で範囲を確認してください。

学習の進め方

まず狭い範囲で取り組み、意味を思い出せないときは「わからない」を選びます。間違えた単語と「わからない」の単語は、このブラウザの苦手リストに保存されます。繰り返し正解してリストから外れた後も、日をあけて意味を確認してください。

関連する教材

  • 番号と意味を単語一覧で確認
  • すし単で意味を選ぶ練習
すし単英単語

すし単

遊び方・練習内容

日本語の意味を見て、対応する英単語の風船を選ぶゲームです。通常モードは30秒で、ALLまたはLv.1〜Lv.4の出題範囲を選べます。英単語を見て訳す練習とは逆に、日本語から英語を思い出します。

学習の進め方

迷う単語が多いときは範囲を絞り、まず正確に選ぶことを優先してください。終了後は苦手単語を確認し、選択肢を見る前に英語を言えるか試します。似た意味の単語も区別したい場合は、しの単で言い換えを練習できます。

関連する教材

  • すし暗で範囲を指定して復習
  • しの単で類義語を確認
しの単synonym

しの単

遊び方・練習内容

表示された英単語と意味が近い英単語を選びます。通常モードは30秒です。日本語訳を手がかりにせず、英語同士の言い換えを確認したいときに使えます。

学習の進め方

学習例として、attempt と try には「試みる」という共通する意味があります。ただし、類義語でも文法や使える場面が常に同じとは限りません。間違えた組をメモし、それぞれの例文で目的語や前置詞も確認してから、もう一度取り組んでください。

関連する教材

  • あんとに単で反対語を確認
  • 長文の中で言い換えを読む
あんとに単antonym

あんとに単

遊び方・練習内容

表示された英単語と反対の意味を持つ単語を選ぶゲームです。一語ずつ覚えた単語を、意味の対として整理する練習に使えます。

学習の進め方

学習例は increase（増える・増やす）と decrease（減る・減らす）です。正解の位置を覚えるのではなく、選ぶ前にそれぞれの意味を思い出してください。否定の接頭辞を付けるだけでは反対語にならない場合もあるため、迷った組は単語ごとに確認します。

関連する教材

  • しの単で意味の近い語を練習
  • 単語の意味を一覧で確認
すしこぶ単古文 × 英語 × 現代語

すしこぶ単

遊び方・練習内容

古文単語に対応する英語を4択で選び、続いて現代語の意味を4択で選びます。途中で一度でも間違えると終了します。英語だけでなく、古文と現代語の意味の違いも確認する教材です。

学習の進め方

古文単語を現代の同じ表記から推測すると、意味を取り違えることがあります。間違えたら古文単語一覧の意味と例文を読み、古文・英語・現代語を一組で確認してください。多義語はこのゲームで扱った訳だけに限定せず、文脈に合う意味を考えます。

関連する教材

  • 古文単語・英訳・例文の一覧
  • 英単語の意味を練習
すし斬り英語タイピング × 30秒斬撃

すし斬り

遊び方・練習内容

表示された英単語をタイピングして寿司を斬る、30秒のゲームです。「並」は1〜1000番、「上」は1001〜2000番の英単語から出題されます。綴りとキー入力を同時に確認できます。

学習の進め方

最初は速度よりも打ち間違いの少なさを優先してください。何度も間違える単語は、入力を止めて文字の並びを確認し、意味と一緒に声に出します。読むと分かる単語でも書けるとは限らないので、練習後に画面を見ずに綴れるか試してください。

関連する教材

  • 出題単語を一覧で確認
  • すしタイプで英文も入力
すしタイプtyping

すしタイプ

遊び方・練習内容

英単語や英作文で使う表現を、画面を見ながらタイピングします。単語のほか、IELTS Task 1・英検向けの表現やテンプレートなどを選べます。タイムアタック、無限練習、対戦があります。

学習の進め方

時間を気にせず確認したいときは無限練習を使ってください。英文は綴りだけでなく意味のまとまりも意識して入力します。練習した表現を自分で使えるか確かめるには、表現集で使い方を読み、英作文練習問題で別の内容の文を書いてみてください。

関連する教材

  • 表現の意味と使い方を読む
  • 表現を使って英作文を書く
すしRUNrun game

すしRUN

遊び方・練習内容

表示された日本語に合う英単語のレーンを、3つの候補から選んで進みます。左右のキーや画面の移動ボタンでレーンを変えます。走行中はライフやコンボを確認しながら解答します。

学習の進め方

英文の速読ではなく、日本語から英単語を選ぶ練習です。操作に慣れるまでは早めに選択肢を読み、迷った語はプレイ後に単語一覧で確認してください。移動操作が難しい場合は、すし暗で同じように意味の判断を練習できます。

関連する教材

  • 迷った単語の意味を確認
  • 移動操作なしで単語を復習
すしRUN 3D3D run game

すしRUN 3D

遊び方・練習内容

3Dコースで正しい英単語のゲートを選び、ジャンプで障害物を避けます。パソコンでは左右キーまたはA・Dで移動、上キーまたはスペースでジャンプできます。画面の操作案内も確認してください。

学習の進め方

英単語の判断と移動操作を同時に行います。最初は距離やコンボより、問題と選択肢を読んで正しく選ぶことを優先します。意味を考える時間が足りない場合は、先にすし暗で語彙を確認してから再挑戦してください。

関連する教材

  • すしRUNの3レーンで練習
  • 単語の意味を落ち着いて復習
すしクロス英単語 × 3Dアクション

すしクロス

遊び方・練習内容

車や電車、川などの障害物に注意して進む、英単語とアクションを組み合わせたゲームです。移動は矢印キー・WASD・スワイプに対応し、語彙の問題では選択肢をタップして答えます。

学習の進め方

移動の失敗と単語の間違いを分けて振り返ってください。操作に気を取られて意味を見落とした場合は、次の問題で単語を先に確認します。意味自体が分からなかった語は単語一覧で読み直すと、何を復習すべきか整理できます。

関連する教材

  • 英単語一覧で意味を調べる
  • 単語の選択に集中して練習
すしFlowながら英単語

すしFlow

遊び方・練習内容

流れてくる英単語を確認する学習モードです。出題レベルや流れる速さを調整でき、一時停止して読み直せます。短い時間で単語に触れたいときや、既習語を確認したいときに使えます。

学習の進め方

眺めただけでは覚えたか判断しにくいため、英語を見たら意味を先に思い出してから表示と照合してください。知らない語は一時停止して確認します。覚えたつもりの語を試すには、すし暗やすし単で実際に答えてみてください。

関連する教材

  • 範囲を決めて理解を確認
  • 選択問題で思い出す練習
すし音読音読・発音ルビ

すし音読

遊び方・練習内容

英文を一文ずつ読み、必要に応じて発音の目安となる「すしルビ」や日本語の補助を確認します。読み上げと速度調整も利用できます。ルビは正確な発音記号ではありません。

学習の進め方

まずルビに頼らず自分で読み、難しかった箇所を読み上げで確認し、もう一度声に出してください。単語の区切りだけでなく音のつながりにも注意します。読み上げの声や利用できる音声は端末・ブラウザによって異なります。

関連する教材

  • すしルビの表記例と読み方
  • 暗唱の進め方を読む
すしTalkslang game

すしTalk

遊び方・練習内容

会話の場面を読み、6つの返答候補から相手に合う表現を選びます。相手の好みや反応を確認しながら、日常会話やスラングの使い方を考えるゲームです。

学習の進め方

単語の直訳が合っていても、相手や場面によって自然な返答は変わります。選んだ後は反応を読み、なぜその返答が合うのか考えてください。くだけた表現は丁寧な場面にそのまま使わず、スラング解説で意味と使用場面を確認します。

関連する教材

  • スラングと日常会話表現を読む
  • 短い英文を自分で組み立てる
すしParts語源ローグライク

すしParts

遊び方・練習内容

手札の単語パーツを2〜4枚組み合わせ、英単語を作ってSUBMITします。正しい単語を作ると攻撃でき、ラウンドの間に手札などを整えるゲームです。接頭辞・語根・接尾辞への気づきに使えます。

学習の進め方

学習例として、re- は「再び」を表すことがあり、reuse は「再使用する」です。ただし、意味が合いそうな部品を並べても実在する単語になるとは限りません。作れた語や迷った語は部品図鑑で意味と組み合わせを確認してください。

関連する教材

  • 英単語の部品図鑑を読む
  • 完成した単語の意味を確認
すし早押し英英定義バトル

すし早押し

遊び方・練習内容

少しずつ表示される英語の定義を読み、当てはまる単語を選びます。難易度によって選択肢の数が変わり、ひとり・対戦・チームで練習できます。誤答すると一定時間、次の回答ができません。

学習の進め方

定義中の知っている一語だけで決めず、特徴を表す語句まで読むことを意識してください。答えを見た後は、その単語を説明するために使われていた表現も確認します。言い換えが難しい場合は、しの単で類義語を先に練習できます。

関連する教材

  • 類義語・言い換えを練習
  • 英文中の定義や説明を読む
すしクイズgeneral quiz

すしクイズ

遊び方・練習内容

地理・音楽・スポーツ・文化などの問題を英語で読み、答えを選びます。ひとりで挑戦するモードや対戦があります。ひとり用では一度の誤答で終了するため、設問と選択肢を落ち着いて確認してください。

学習の進め方

答えを知っているかだけでなく、何を尋ねる英文か読み取る練習に使えます。答え合わせでは解説も読み、知らなかった知識と分からなかった英語を分けてメモしてください。世界史に取り組みたい場合は、す界しで時代を選んで学べます。

関連する教材

  • 英語で世界史を学ぶ
  • 英語の定義から単語を選ぶ
すしイディオム高校英語イディオム

すしイディオム

遊び方・練習内容

英語→日本語・日本語→英語の4択で熟語を練習します。通常モードは60秒で、誤答すると残り時間が2秒減ります。連続正解でスコア倍率が上がります。

学習の進め方

take off と put off のように同じ前置詞・副詞を含んでいても、熟語全体の意味は違います。選ぶ前に意味を思い出してください。間違えた熟語はこのブラウザの復習リストに保存され、復習で同じ熟語に2回連続正解するとリストから外れます。翌日にも意味を確認すると、覚えたか判断できます。

関連する教材

  • 短い英文を作る練習
  • 英作文で使う表現を確認
すし単ジュニア小中学生向け

すし単ジュニア

遊び方・練習内容

小中学生向けの入口ページです。現在は「すしクロック」で時計と英語の時刻表現を練習できます。ページ内には時刻の読み方の例と、家庭・授業での練習方法を掲載しています。

学習の進め方

最初に数字の読み方を確認し、時計を見て何時何分か日本語で答えてから英語にしてみてください。慣れてきたら英語だけで答えます。間違えたときは、時と分のどちらを読み違えたか分けて確認すると復習しやすくなります。

関連する教材

  • すしクロックで時刻を練習
  • 時刻の読み方と練習方法
すし瞬瞬間英作文

すし瞬

遊び方・練習内容

日本語の文から英文を組み立てる瞬間英作文です。50文を10文ずつのセットで練習し、「英文を見る」で解答と短い文法説明を確認します。「もう一度」「言えた」で自分の理解を記録します。

学習の進め方

答えを表示する前に、一度最後まで英文を言ってください。例文と違っても正しい表現はありますが、まずは練習対象の文法を使えたか比べます。自動で発音や英文を採点する機能ではないため、主語・時制・語順を自分で確認してください。

関連する教材

  • 英文を作るための表現集
  • 英文を声に出して読む練習
シャリ単テーマ別英単語

シャリ単

遊び方・練習内容

テーマ別の単語セットや、自分で入力した英語・日本語のリストを使って練習します。日本語に合う英単語を選ぶゲームなので、授業や読書で出会った語をまとめて復習したいときに使えます。

学習の進め方

自分のリストには、英語と意味を一組ずつ入力してください。多義語は一度に意味を詰め込まず、今回覚えたい訳を選ぶと問題が分かりやすくなります。同じ訳の候補が増えて迷う場合は、元の例文を確認し、リストの表現を見直してください。

関連する教材

  • リスト作りの参考に単語一覧を見る
  • 既存の番号範囲で練習
すし性格診断What Would You Do?

すし性格診断

遊び方・練習内容

50の場面から毎回20問が出題され、英語の質問に自分に近い返答を選びます。結果に出てくる性格を表す英単語や、自己紹介の表現を学ぶためのコンテンツです。

学習の進め方

正解を当てる問題ではありません。結果の形容詞の意味を確認し、自分に合うものを使って短い自己紹介を作ってください。たとえば I am curious. は「私は好奇心が強いです」です。結果は専門的な心理検査ではなく、英語で自分を説明する練習の参考にしてください。

関連する教材

  • 日本語から英文を作る練習
  • 自分について話す例を読む
す界し英語で世界史

す界し

遊び方・練習内容

時代を選び、一問一答・正誤・ヒント・組み合わせ・時系列などの問題で世界史を学びます。日本語訳と日英の解説を確認でき、間違えた問題を復習できます。

学習の進め方

最初は学習した時代に絞り、英語の設問を読んでから必要に応じて日本語訳を確認してください。年号だけでなく、出来事の前後関係や原因を解説と合わせて整理します。知らない歴史事項と、意味が分からなかった英語を分けて記録すると復習の対象が明確になります。

関連する教材

  • ほかの分野の英語クイズ
